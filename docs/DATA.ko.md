# Sprag 이 보내는 데이터

[← README](../README.ko.md) · [English](./DATA.md)

이 문서는 오픈소스 CLI, Pro, Enterprise 를 쓸 때 컴퓨터에서 무엇이 나가는지 플랜별로 정리합니다. 모든 항목은 이 저장소의 코드와 대조할 수 있도록 근거 파일을 함께 적었습니다. 확인 기준은 sprag-cli 3.97 입니다.

## 요약

- **오픈소스(무료 CLI)**: 사용자를 알아볼 수 있는 데이터는 Sprag 서버로 가지 않습니다. 계정도 없습니다. 밖으로 나가는 요청은 새 버전 확인과 공개 프리셋 확인 같은 익명 조회뿐이며, 요청 본문에 사용 기록이나 식별자가 없습니다.
- **Pro**: 팀에 참여한 컴퓨터만 하루에 한 행씩 숫자 집계를 올립니다. 지출, 절감액, 위임 횟수 같은 값입니다. 프롬프트, 코드, 파일 경로, 프로젝트 이름은 올라가지 않습니다.
- **Enterprise**: Pro 와 같은 집계를 올립니다. 조직 오너나 어드민이 팀별로 프롬프트 수집을 켠 경우에만 사용자가 직접 입력한 프롬프트가 추가로 올라갑니다. 비밀값과 개인정보는 업로드 전에 사용자 컴퓨터에서 가립니다. 켜기 전에 쓴 기록은 올리지 않습니다.

팀 기능은 `sprag team join` 을 실행하거나 조직이 `SPRAG_TEAM_TOKEN` 을 배포해야 켜집니다. 그 전까지는 Pro 나 Enterprise 계약이 있어도 컴퓨터가 집계를 보내지 않습니다.

## 오픈소스 (무료 CLI)

Sprag 의 분석은 Claude Code 와 Codex 가 이미 컴퓨터에 남긴 세션 기록을 읽어서 합니다. statusline, route-scan, 절감 원장, doc2md 변환은 모두 로컬 파일만 씁니다. statusline 을 그리는 동안 네트워크를 기다리지도 않습니다. 아래 요청은 분리된 자식 프로세스가 보내고 화면은 캐시된 답만 읽습니다.

### Sprag 이 보내는 익명 요청

| 목적지 | 시점 | 보내는 내용 | 끄는 방법 |
|---|---|---|---|
| npm 레지스트리의 `sprag-cli/latest` | 하루 한 번 안팎 | 요청만 보냅니다. 레지스트리 인증 토큰도 붙이지 않습니다 | `SPRAG_NO_UPDATE_CHECK=1` |
| `api.github.com/repos/rootstudioyaml/sprag/releases/tags/<버전>` | 새 버전이 보일 때만 | 요청만 보냅니다. 릴리스 핵심 세 줄을 받아 옵니다 | 위와 같음 |
| Sprag 프리셋 서버(Supabase)의 `presets_version`, `presets_published` | 최대 24시간에 한 번 | 요청만 보냅니다. 누구에게나 같은 공개 키를 쓰고 구성원 키나 기기 ID 는 붙이지 않습니다 | `SPRAG_NO_PRESET_SYNC=1` |

프리셋 서버의 두 함수는 게시된 프리셋을 읽기만 하는 SQL 조회이며 요청한 쪽에 대해 아무것도 기록하지 않습니다. 받은 프리셋은 CLI 에 들어 있는 공개 키로 서명을 확인한 뒤에만 적용합니다. 다만 인터넷의 모든 요청과 마찬가지로 받는 서버에는 접속한 IP 주소가 보입니다.

근거: `src/update-check.js`, `src/preset-sync.js`, `src/presets-source.js`

### 사용자를 대신해 다른 곳으로 가는 요청

다음 요청은 Sprag 서버로 가지 않습니다. 사용자가 이미 쓰고 있는 서비스에 사용자의 인증 정보로 접속합니다.

| 목적지 | 조건 | 내용 | 끄는 방법 |
|---|---|---|---|
| `api.anthropic.com/api/oauth/usage` | claude.ai 계정으로 로그인했고 요금제가 Pro 나 Max 가 아닐 때(Team, Enterprise 등). 예산 게이지를 그리는 데 씁니다 | Claude Code 가 저장한 로그인 토큰을 Anthropic 에만 보냅니다. 토큰은 메모리에서만 쓰고 파일이나 로그에 적지 않습니다 | `sprag mode no-oauth-budget` 또는 `SPRAG_OAUTH_BUDGET=0` |
| 사용자의 LiteLLM 게이트웨이 | `ANTHROPIC_BASE_URL` 이 게이트웨이를 가리킬 때 | 이미 쓰는 게이트웨이 키로 예산과 단가를 조회합니다. 키는 캐시 파일에 적지 않습니다 | `ANTHROPIC_BASE_URL` 해제 또는 예산 세그먼트 제거 |
| npm, PyPI | `sprag upgrade` 를 수락했거나 doc2md 변환기를 설치할 때 | 일반 패키지 설치입니다 | 설치를 거절합니다 |
| GitHub 이슈 또는 익명 Google Form | `sprag feedback` 을 직접 실행할 때만 | 입력한 메시지와 Sprag 버전, OS, Node.js 버전 | 명령을 실행하지 않으면 됩니다 |

근거: `src/oauth-budget.js`, `src/litellm-budget.js`, `src/gateway-spend.js`, `src/commands/feedback.js`. 목적지 전체 목록은 [설치 안내의 네트워크 표](./INSTALL.ko.md#네트워크-접근)에 있습니다.

## Pro

### 언제부터 보내나

컴퓨터는 두 경우에만 팀에 참여합니다. 사용자가 `sprag team join <토큰>` 을 실행하면 올라갈 항목 목록을 먼저 보여 주고 확인을 받습니다. 조직이 셸 프로필이나 Claude Code 관리 설정에 `SPRAG_TEAM_TOKEN` 을 넣어 두면 다음 세션에서 참여하고, 첫 세션에 팀 이름과 확인 명령을 한 줄로 알립니다.

### 올라가는 것

참여한 컴퓨터는 로컬 날짜마다 한 행을 올립니다. 업로드는 5분에 한 번 이하이고 한 번에 최근 30일까지 보냅니다.

- **금액**: Claude 지출, Codex 지출, 게이트웨이 지출, 총지출, 위임 비용, 서브에이전트 비용, 절감액(모두 USD), 모델 계열별 지출(`opus`, `sonnet` 같은 이름 단위)
- **횟수**: 위임 실행 횟수, 모델 계열 비중, 가격을 몰라 계산에서 뺀 건수
- **기기**: OS 이름과 버전(예: macOS 26), Sprag 버전, 에이전트 종류(`claude` 또는 `codex`), 표시 이름, 기기 ID
- **게이트웨이 사용자 해시**: LiteLLM 게이트웨이를 쓸 때만 보냅니다. 게이트웨이 주소와 사용자 ID 를 합쳐 해시한 값의 앞 16자리이며, 한 사람의 컴퓨터 두 대를 한 번만 세는 데 씁니다
- **위임 룰 요약**: 카테고리와 티어마다 위임 횟수, 실패율, 절감액, 상한, 시작일 같은 숫자만 담습니다

표시 이름과 기기 ID 의 기본값은 컴퓨터마다 한 번 만드는 `member-3f9a2c71` 같은 무작위 값입니다. 예전에는 OS 로그인 이름을 썼지만 실명이 서버에 올라갈 수 있어 무작위 ID 로 바꿨습니다. 실명을 쓰고 싶으면 `sprag team name "이름"` 으로 직접 정합니다. CPU 아키텍처 칸은 서버 함수의 인자로 남아 있지만 항상 빈 값을 보냅니다.

위임 룰 요약에는 허용 목록을 적용합니다. 원본 룰 파일에는 프로젝트 경로와 프롬프트 발췌가 들어 있어서, 요약은 정해진 키 12개에 숫자와 정해진 단어만 채운 새 객체로 다시 만듭니다. `test/team-rule-stats.test.js` 가 키 목록을 고정하고 경로나 예시 문장이 결과에 남지 않는지 검사합니다.

근거: `src/team-sync.js` 의 `aggregateDaily`, `deviceInfo`, `src/member-id.js`, `src/team-rule-stats.js`

### 받아 오는 것

같은 동기화에서 조직이 승인한 룰과 조직 최소 버전, 대시보드 순위(statusline 의 `team` 칩)를 받아 옵니다. 조직 최소 버전보다 낮은 컴퓨터는 다음 세션에서 스스로 업그레이드합니다. Sprag 이 묻지 않고 패키지를 설치하는 경우는 이것 하나뿐입니다.

### 누가 보나

조직의 오너와 어드민은 sprag.io/team 에서 구성원별 하루 합계를 봅니다. 세션 내용이나 프롬프트는 볼 수 없습니다. Sprag 운영자는 지원과 결제 처리를 위해 운영 콘솔에서 조직 단위 합계와 좌석 상태를 봅니다.

## Enterprise

Enterprise 는 Pro 의 집계를 그대로 올리고 프롬프트 수집 기능을 더합니다. 이 기능은 꺼진 상태로 시작합니다. 조직 오너나 어드민이 대시보드에서 팀마다 켜야 하고, 구성원은 `sprag team status` 에서 "프롬프트 수집: 켜짐" 여부를 확인할 수 있습니다.

### 수집하는 것

메인 Claude Code 세션과 Codex 세션에서 사용자가 직접 입력한 프롬프트만 올라갑니다. 프롬프트 하나마다 다음 세 값을 보냅니다.

- 입력한 시각
- 프로젝트 폴더 이름(경로의 마지막 부분 하나이며 전체 경로는 보내지 않습니다)
- 본문(최대 20,000자)

프롬프트에 직접 붙여 넣은 텍스트는 본문에 포함됩니다. 회사 정책상 민감한 코드나 문서를 프롬프트에 붙여 넣는다면 이 점을 구성원에게 알려 주십시오.

### 보내지 않는 것

어시스턴트 답변, 도구 출력, Claude 가 읽은 파일 내용, 서브에이전트 기록, 슬래시 명령 래퍼, 시스템 알림, 로컬 경로, 백그라운드 작업 알림, 다른 에이전트가 보낸 메시지, `!` 로 실행한 셸 명령과 그 출력은 올라가지 않습니다. 기록 파일 경로도 보내지 않습니다. 파일을 구분할 때는 경로를 SHA-256 으로 해시한 값의 앞 16자리를 씁니다.

### 업로드 전에 가리는 것

가림은 업로드 전에 사용자 컴퓨터에서 처리합니다.

| 종류 | 바뀌는 표지 |
|---|---|
| API 키와 토큰 (`sk-...`, `sk-ant-...`, `ghp_...`, `github_pat_...`, `AKIA...`, `xox?-...`), `Bearer` 토큰, 개인 키 블록, `KEY=`, `TOKEN=`, `PASSWORD=`, `SECRET=` 꼴의 대입 | `[redacted]` |
| 이메일 주소 | `[redacted:email]` |
| 한국 전화번호 | `[redacted:phone]` |
| 주민등록번호 | `[redacted:rrn]` |
| 카드번호 | `[redacted:card]` |

패턴은 코드 조각을 망가뜨리지 않는 쪽으로 맞췄습니다. 그래서 모양이 특이한 비밀값은 놓칠 수 있습니다. 비밀값은 프롬프트에 넣지 않는 것이 가장 안전합니다.

### 과거 기록은 올리지 않습니다

컴퓨터가 수집이 켜진 것을 처음 보면 모든 기록 파일의 현재 끝을 시작점으로 표시합니다. 그 뒤에 입력한 프롬프트만 올라가므로 정책이 닿기 전의 대화는 나가지 않습니다. 수집이 꺼지면 시작점 파일을 지우고, 다시 켜면 그 시점의 끝에서 새로 시작합니다. 꺼져 있던 동안 입력한 프롬프트도 나중에 올라가지 않습니다.

### 누가 보나

수집된 프롬프트는 그 조직의 오너와 어드민이 sprag.io/team 의 프롬프트 탭에서 봅니다. Sprag 운영자(슈퍼유저)도 지원과 장애 대응을 위해 운영 콘솔에서 같은 화면을 열 수 있습니다. 서버 함수 `prompt_access_check` 가 이 두 역할과 Enterprise 요금제만 통과시키며, Pro 조직에는 프롬프트 탭이 잠겨 있습니다.

근거: `src/team-prompts.js`

## 서버 보관과 보안

- **저장 위치**: Supabase 의 서울 리전(ap-northeast-2)
- **전송 구간**: Sprag 서버로 가는 요청은 모두 HTTPS 입니다
- **접근 경로**: 컴퓨터는 테이블에 직접 쓰지 못하고 정해진 서버 함수만 부릅니다. 각 함수는 멤버 키를 확인한 뒤 그 멤버의 행만 다룹니다. 대시보드는 행 단위 접근 제어로 자기 조직의 데이터만 보여 줍니다
- **멤버 키**: 사용자 데이터 디렉터리의 `team.json` 에 권한 0600 으로 보관합니다
- **보관 기간**: 조직을 닫은 뒤 30일 안에 조직 데이터를 지웁니다. 오너나 어드민이 제거한 컴퓨터를 "삭제"하면 그 컴퓨터의 사용 기록과 프롬프트가 바로 지워집니다
- **제3자 제공**: 데이터를 팔지 않습니다. 처리 위탁 업체는 [개인정보처리방침](https://sprag.io/privacy/)에 적었습니다
- **웹사이트**: sprag.io 에는 광고 쿠키와 분석 스크립트가 없습니다

## 직접 확인하는 방법

`sprag team status --show-payload` 는 다음 동기화에서 올라갈 기기 정보, 하루 단위 행, 위임 룰 요약을 그대로 출력합니다. Enterprise 수집이 켜져 있으면 대기 중인 프롬프트 수와 예시 하나의 앞 80자도 보여 줍니다. 네트워크에 접속하지 않고 로컬에서만 계산합니다.

모든 전송을 끄려면 아래 세 줄을 셸 프로필에 넣고 `sprag mode no-oauth-budget` 을 한 번 실행합니다.

```bash
export SPRAG_NO_UPDATE_CHECK=1   # 버전 확인과 프리셋 확인
export SPRAG_NO_PRESET_SYNC=1    # 프리셋 확인
export SPRAG_NO_TEAM_SYNC=1      # 팀 업로드 전부
```

`SPRAG_NO_TEAM_SYNC=1` 을 켠 컴퓨터는 팀에 참여해 있으면 "업로드를 멈췄다"는 상태 호출을 한 번 보냅니다. 사용량 데이터는 들어 있지 않으며 대시보드가 멈춘 컴퓨터와 연락이 끊긴 컴퓨터를 구분하는 데 씁니다. 팀에서 완전히 나가려면 `sprag team leave` 를 실행합니다.

CLI 코드는 Apache-2.0 라이선스로 공개되어 있습니다. 위에 적은 근거 파일을 직접 읽어 확인할 수 있고, 팀 기능의 세부 사항은 [팀 기능 안내](./TEAM.ko.md)에 있습니다.
