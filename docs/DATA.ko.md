# Sprag가 보내는 데이터

[← README](../README.ko.md) · [English](./DATA.md)

Sprag 서버로 데이터를 올리는 경우만 플랜별로 정리했습니다. 새 버전 확인처럼 내려받기만 하는 조회는 아무것도 올리지 않으므로 뺐습니다.

| 플랜 | 서버로 올리는 것 |
|---|---|
| 오픈소스 (무료 CLI) | 없음 |
| Pro | 팀에 참여한 컴퓨터의 하루 단위 숫자 집계 |
| Enterprise | Pro 의 집계, 그리고 수집을 켠 팀에 한해 직접 입력한 프롬프트 |

## 오픈소스

올리는 데이터가 없고 계정도 필요 없습니다. 분석은 모두 컴퓨터에 있는 세션 기록으로 합니다. `sprag feedback` 을 직접 실행했을 때만 입력한 메시지와 버전, OS 가 전달됩니다.

## Pro

`sprag team join` 을 실행하거나 조직이 `SPRAG_TEAM_TOKEN` 을 배포한 컴퓨터만 올립니다. 참여하기 전에는 계약이 있어도 아무것도 올라가지 않습니다.

**올리는 것** (하루 한 행)
- 지출, 절감액, 위임 비용(USD)과 위임 횟수
- 모델 계열별 지출과 비중(`opus`, `sonnet` 같은 이름 단위)
- OS 이름과 버전, Sprag 버전, 표시 이름(기본값은 `member-3f9a2c71` 같은 무작위 ID)
- 위임 룰 요약: 카테고리별 횟수, 실패율, 절감액 같은 숫자만

**올리지 않는 것**: 프롬프트, 대화 기록, 코드, 파일 경로, 프로젝트 이름, 룰 본문, API 키, 호스트 이름, 오류 메시지

조직의 오너와 어드민은 구성원별 하루 합계만 볼 수 있습니다.

## Enterprise

Pro 와 같은 집계를 올립니다. 조직 오너나 어드민이 팀별로 프롬프트 수집을 켠 경우에만 다음이 더해집니다.

- 메인 세션에 직접 입력한 프롬프트의 본문(최대 20,000자), 입력 시각, 프로젝트 이름이 아닌 이 컴퓨터 전용 별칭(`p-` 뒤에 16진수 10자)
- API 키, 토큰, 비밀번호, 이메일, 전화번호, 주민등록번호, 카드번호는 `[redacted]`, 네트워크 주소는 `<host>`, URL은 `<url>`, 파일 경로는 `<path>` 로 모두 업로드 전에 컴퓨터에서 가립니다
- 수집을 켜기 전에 쓴 기록은 올리지 않습니다
- 어시스턴트 답변, 도구 출력, 파일 내용은 올리지 않습니다

프롬프트는 그 조직의 오너와 어드민, 그리고 지원을 맡은 Sprag 운영자만 볼 수 있습니다.

## 확인하고 끄기

- `sprag team status --show-payload`: 다음에 올라갈 내용을 그대로 보여 줍니다
- `SPRAG_NO_TEAM_SYNC=1`: 업로드를 모두 멈춥니다
- `sprag team leave`: 팀에서 나갑니다

데이터는 Supabase 서울 리전에 HTTPS 로 저장되며 조직을 닫으면 30일 안에 지웁니다. 문의는 support@sprag.io 로 보내 주십시오. 세부 항목은 [팀 기능 안내](./TEAM.ko.md)에 있습니다.
