# 클로드 코드 5시간·주간 사용 한도 이해하기

[← README](../README.ko.md) · [English](./GUIDE-USAGE-LIMITS.md)

클로드 코드는 두 개의 롤링 윈도우로 사용량을 관리합니다. 짧은 쪽(대략 5시간)과 긴 쪽(대략 7일)이고, 둘 다 각자 리셋 시각이 따로 있습니다. 둘 중 하나라도 다 차면 그 윈도우가 리셋될 때까지 새 요청을 보낼 수 없습니다. 작업 도중에 막히지 않으려면 요청이 거절되고 나서 알아채기보다 진행 중에 사용량을 계속 지켜보는 편이 빠르고, 턴마다 드는 토큰을 줄이면 같은 윈도우로 더 오래 버틸 수 있습니다.

## 왜 일 단위가 아니라 윈도우 단위인가

두 윈도우는 각자 리셋 주기로 따로 돌아갑니다. 짧은 윈도우는 차고 몇 시간 뒤 리셋되고, 긴 윈도우는 주간 주기로 리셋됩니다. 서로 독립적이라 한쪽은 여유가 있는데 다른 쪽은 거의 다 찬 상태가 얼마든지 생길 수 있습니다. 주 초반에 무거운 세션을 몰아 쓰면 5시간 윈도우는 중간중간 깨끗하게 리셋되는데도 주간 윈도우만 먼저 바닥날 수 있습니다. 그래서 "아직 막힌 적 없으니 괜찮다"는 판단은 위험합니다. 두 숫자를 따로 확인해야 실제로 얼마나 여유가 있는지 알 수 있습니다.

## 막히기 전에 두 윈도우를 함께 봐야 합니다

아직 확인 습관이 없다면, 챙겨야 할 건 각 윈도우가 얼마나 찼는지와 언제 리셋되는지입니다. 클로드 코드에서도 요청하면 각 윈도우를 얼마나 썼는지 확인할 수 있습니다. 다만 이 숫자를 작업하는 내내 눈앞에 계속 띄워 주거나 한도에 가까워지기 전에 미리 경고해 주지는 않습니다. 그러려면 직접 확인하거나 그걸 대신 해 주는 도구가 필요합니다.

## 턴당 비용을 줄이면 윈도우가 더 오래 갑니다

무거운 턴일수록 윈도우를 빨리 소진하므로, 실질적인 해법은 비용을 줄이는 방법과 같습니다. 턴당 토큰이 적을수록 윈도우가 차기 전까지 더 많은 턴을 쓸 수 있습니다.

- **`/compact`와 `/clear`를 제때 쓰세요.** 압축되거나 초기화되기 전까지 누적된 맥락은 매 턴 다시 청구됩니다. 자동 압축을 기다리지 말고 작업이 바뀌는 시점에 직접 실행하면 세션이 더 가벼워집니다. 자세히: [클로드 코드 토큰 사용량 줄이는 법](./GUIDE-REDUCE-TOKENS.ko.md)
- **읽을 게 많은 작업은 서브에이전트로 넘기세요.** 코드베이스를 탐색해서 짧은 답만 돌려주는 서브에이전트를 쓰면 탐색 토큰이 메인 컨텍스트 밖에 남아서 메인 세션의 윈도우가 천천히 찹니다.
- **큰 문서는 첨부 전에 변환하세요.** pptx나 PDF를 원본 그대로 첨부하면 프롬프트 자체보다 수만 토큰이 더 들 수 있습니다. 실측 절감치는 [doc2md](./DOC2MD.ko.md) 문서를 참고하세요.
- **비용을 아끼려고 세션 중간에 모델을 바꾸지 마세요.** 도움이 될 것 같지만 프롬프트 캐시는 모델별로 따로 유지되므로, 중간에 바꾸면 캐시가 콜드 상태로 초기화돼서 대화 전체를 전체 요금으로 다시 읽게 됩니다. 자세히: [실시간 라우팅이 더 비싼 이유](./NOT-A-ROUTER.ko.md)

## Sprag가 더하는 것: 매 턴마다 두 윈도우를 스테이터스라인에

Sprag의 스테이터스라인은 매 렌더마다 현재 세션·주간 사용 한도 윈도우를 읽어서 리셋 시각과 함께 진행 막대로 보여줍니다. 예를 들면 이렇습니다.

```
✦ current ▰▰▰▰▰▰▰▱▱▱▱▱ 62% 🔄 21:33 · 📅 weekly ▰▰▰▰▰▱▱▱▱▱▱▱ 38% 🔄 Tue 19:33
```

둘 중 하나라도 90%를 넘으면 해당 칩이 빨간 경고(`🚨 5H NN%` 또는 `🚨 7D NN%`)로 바뀌면서 줄 맨 앞으로 옮겨 갑니다. 다른 세그먼트 사이에서 눈치채야 하는 게 아니라 가장 먼저 보이게 됩니다. 두 윈도우가 동시에 90%를 넘으면 더 빨리 리셋되는 쪽이 빨간 경고로 승격되고 나머지 하나는 강조된 세그먼트로 남습니다. 다음에 뭘 해야 할지 결정할 때 더 빨리 리셋되는 쪽이 실제로 중요하기 때문입니다. 세그먼트 전체 설명은 [스테이터스라인 레퍼런스](./STATUSLINE.ko.md)에 있습니다.

한도가 정말 임박해서 클로드 코드가 멈추기 전에 작업 상태를 남겨야 할 때는 `sprag handoff`가 세션의 깃 상태, 모델, 기록된 컨텍스트·토큰 사용량, 현재 한도까지 마크다운 파일 하나에 정리해서 남겨 줍니다. 윈도우가 리셋된 뒤 새 세션에서 그대로 이어받으면 됩니다.

```bash
npm i -g sprag-cli
sprag mode 7d     # 스테이터스라인의 절감 표시 윈도우를 7일로 전환
```
