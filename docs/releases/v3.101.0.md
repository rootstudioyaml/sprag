- **The delegation ledger stores token counts and computes dollars when it is read.** Each delegated run keeps its time and its tokens per rate class, and its saving and cost are priced at the rate in effect then (stage 2 of [#15](https://github.com/rootstudioyaml/sprag/issues/15)), so a price correction reprices the past correctly and the team dashboard re-uploads from the first changed day; older events without token counts keep their stored amount.
- **Session costs are priced at the rate of the day the tokens were spent.** A session that crosses UTC midnight is priced day by day, and month spend, statusline cost, team daily cost and model share all use the same method; a new usage ledger keeps token totals per session, day and model, so month spend still counts sessions whose transcripts Claude Code has deleted, and the session cache is rebuilt once after upgrading.
- **LiteLLM gateway prices are recorded by date and used by date.** Each gateway price refresh is recorded when prices change, and gateway sessions and delegated runs are priced from the gateway's table on that day, never filled from list prices; the Codex list table also gains `gpt-6.1-terra`, `gpt-5-mini`, `gpt-5-nano` and `gpt-5-pro`.

## 한국어

- **위임 원장이 금액 대신 토큰 수를 저장하고 금액은 읽을 때 계산합니다.** 위임 실행마다 그 시각과 단가 종류별 토큰 수를 남기고 절감액과 실행 비용은 그 시각의 가격으로 계산합니다([#15](https://github.com/rootstudioyaml/sprag/issues/15)의 2단계). 가격표를 정정하면 지난 기간 금액도 바르게 다시 계산되고 팀 대시보드에는 바뀐 날짜부터 다시 올라갑니다. 토큰 수가 없는 오래된 이벤트는 저장된 금액을 그대로 씁니다.
- **세션 비용도 토큰을 쓴 날의 가격으로 계산합니다.** UTC 자정을 넘긴 세션은 날마다 그날 가격으로 계산하고 월 지출, 상태줄 비용, 팀 일별 비용, 모델 점유율이 모두 같은 방식을 씁니다. 새 사용량 원장이 세션별 날짜와 모델별 토큰 수를 남기므로 Claude Code가 오래된 대화 기록을 지워도 이번 달 지출에서 빠지지 않습니다. 업그레이드 후 첫 실행 때 세션 캐시를 한 번 다시 만듭니다.
- **LiteLLM 게이트웨이 가격도 날짜별로 기록하고 그날 가격으로 계산합니다.** 게이트웨이 가격표를 받을 때 바뀐 경우에만 기록을 남기고 게이트웨이를 거친 세션과 위임 실행을 그 날짜의 게이트웨이 가격으로 계산합니다. 정가표로 게이트웨이 가격을 대신 채우지 않는 원칙은 그대로입니다. Codex 정가표에는 `gpt-6.1-terra`, `gpt-5-mini`, `gpt-5-nano`, `gpt-5-pro`를 추가했습니다.
