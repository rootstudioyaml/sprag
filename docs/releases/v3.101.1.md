- **The delegation hint stays quiet on replies to the previous turn and on feedback.** Prompts that continue the conversation ("응 …", "그래 네가 돌려봐", "아니면 …"), feedback such as "…가 아니야", and the user saying they will check something only make sense with the conversation, so they get no hint.
- **Outward actions, edit requests and long written specs get no hint either.** That covers uploading, posting, sending, deleting and paying, edits such as change, add and set up, and specs over 100 characters that are not pasted logs; on 600 real prompts, hints that needed the main model fell from 36 of 47 to 16 of 25 ([#16](https://github.com/rootstudioyaml/sprag/issues/16)).
- **Commands and lookups such as `git push`, running tests and checking a version keep their hint.** The Codex prompt hint applies the same gates.

## 한국어

- **앞 턴에 답하거나 피드백을 주는 말에는 위임 힌트가 나오지 않습니다.** "응 …", "그래 네가 돌려봐", "아니면 …"처럼 앞 대화를 이어 가는 말과 "…가 아니야" 같은 피드백은 무슨 일을 하라는지 대화를 봐야 알 수 있어서 힌트를 내지 않습니다. "확인해볼게"처럼 사용자가 직접 확인하겠다는 말도 마찬가지입니다.
- **바깥으로 나가는 작업, 수정 요청, 긴 요구 사항 글에도 힌트를 내지 않습니다.** 업로드, 게시, 발송, 삭제, 결제와 변경, 추가, 설정 같은 수정 요청, 로그가 아닌 100자 넘는 요구 사항 글이 해당합니다. 실제 프롬프트 600건으로 잰 결과 main 모델이 필요한데 힌트가 나간 경우가 47건 중 36건에서 25건 중 16건으로 줄었습니다([#16](https://github.com/rootstudioyaml/sprag/issues/16)).
- **`git push`, 테스트 실행, 버전 확인 같은 명령과 조회는 지금처럼 힌트를 받습니다.** Codex 쪽 프롬프트 힌트도 같은 조건을 씁니다.
