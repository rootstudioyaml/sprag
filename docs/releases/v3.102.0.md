- **The statusline has its own ultracode chip, `🐙 ultra on`.** Since Claude Code 2.1.302 ultracode is a session toggle independent of the effort level, so the effort chip now shows only the real level (`🔬 high`) and the new chip right after it shows ultracode: a bold rainbow when on, a gray `🐙 ultra off` when off. Before, ultracode was only checked at xhigh, so a session on high with ultracode on read as plain `high`.
- **The new `/effort` output of 2.1.302 is read.** `Ultracode on (…)`, `Ultracode off.` and the ` · Ultracode on` suffix on the effort query set the state; a plain level change leaves it alone, and the wording of earlier versions still reads. Place the chip with `--segments` as `ultra`.
- **Open web research and subagent reports get no delegation hint.** Real transcripts showed open-ended research (news, community reaction, comparing alternatives) handed to a cheaper model ending without the main finding, and a background subagent's report or a system notification is not a user request.
