- **Owners, admins and the superuser sign in with an authenticator app as well.** sprag.io/team and sprag.io/ops ask for the email code and then a code from any app that makes 6-digit codes (TOTP, Google Authenticator for example). The first sign-in enrolls the app from a QR code; later sign-ins take the code alone. The team server refuses every admin action to a session that skipped the app or is older than seven days, and shows such a session empty tables. The Free plan has no session expiry, so a session copied out of browser storage used to live forever; this closes that. The organization panel shows which admins have enrolled, an owner resets the app of an admin who lost the phone, the superuser resets anyone's, and the account menu replaces your own. The account gets a mail when an app is added or removed. Members and `sprag team join` never sign in, so nothing changes for them.
- **`sprag team create` takes the authenticator code.** It asks for the app code after the email code, or takes `--app-code <code>` without a terminal, and tells an account without an app to enroll one on sprag.io/team first.
- **The dashboard pages pin the CDN script.** /team, /ops and /order load supabase-js with an SRI hash, so the browser refuses the file if the CDN copy changes.
- **The sign-in code request passes a Cloudflare Turnstile check.** sprag.io/team and sprag.io/ops show the check above the Send code button and the team server refuses a request without it, so a script can no longer empty the project's hourly mail quota by asking for codes for a known owner address, or create accounts for arbitrary addresses. `sprag team create` no longer requests the code itself: it opens sprag.io/team, where you request it, and takes the emailed code in the terminal.
- **The effort guard takes the top line of the statusline.** `🔬🔥 Effort guard ×3 since 11/1  |  sonnet medium→high` counts the Sonnet delegations sent without an effort that the guard ran at high, with the same reset mark as Routing saved. It used to sit under the savings as `🔬 Effort saved $0.45`, and that was wrong: a raise spends more tokens, and what it prevents is a silently wrong result that nobody would know to rerun, so no amount belongs to it. The line now carries the count alone and sits above the savings as the quality measure it is. The single-line layout keeps the `🔬↑N` chip, and `sprag saved` adds what the raised runs cost.
- **The team line says what percentile you are at, and why it does not move when you are alone.** When the team server sends no score percentile, the line reads it off the rank with the office page's arithmetic: rank r of n is (n−r)/(n−1), and the people to pass for the next species follow the same formula, so `now 75%, 2 pts more for 🐆 Cheetah (pass 1)` appears whether or not the server is updated. Alone in the standings the percentile is 50% by definition and the species stays the 🐱 Cat, so the line says `now 50%, fixed while alone · standings start when a colleague joins`, and the next-species line of `sprag team status` explains the same. The delegation-share rule of the six species from the Wolf up needs the company median from the server, so until then the line names the rule without the figure.

## 한국어

- **오너, 어드민, 슈퍼유저 로그인에 인증 앱이 붙습니다.** sprag.io/team 과 sprag.io/ops 는 이메일 코드 뒤에 Google Authenticator처럼 6자리 코드를 만드는 앱(TOTP)의 코드를 받습니다. 처음 로그인할 때 QR 코드를 스캔해 앱을 등록하고 그다음부터는 코드만 입력합니다. 팀 서버는 인증 앱을 거치지 않은 세션과 로그인한 지 7일이 지난 세션에 관리자 작업을 전부 거절하고 테이블도 비워 보여 줍니다. 무료 요금제에는 세션 만료 설정이 없어서 브라우저 저장소에서 복사한 세션이 영원히 살아 있던 문제를 이렇게 막습니다. 조직 패널은 어느 어드민이 앱을 등록했는지 보여 주고 오너는 휴대폰을 잃은 어드민의 앱을 초기화하며 슈퍼유저는 누구의 앱이든 초기화합니다. 계정 메뉴의 '인증 앱 교체'로 본인 앱을 바꿉니다. 앱이 등록되거나 삭제되면 그 계정에 메일이 갑니다. 멤버와 `sprag team join` 은 로그인하지 않으므로 달라지는 것이 없습니다.
- **`sprag team create` 가 인증 앱 코드를 받습니다.** 이메일 코드 뒤에 앱 코드를 묻고 터미널이 없으면 `--app-code <코드>` 로 받습니다. 아직 앱이 없는 계정에는 sprag.io/team 에서 먼저 등록하라고 안내합니다.
- **대시보드 페이지가 CDN 스크립트의 무결성 해시를 확인합니다.** /team, /ops, /order 가 불러오는 supabase-js 에 SRI 해시가 붙어 CDN 쪽 파일이 바뀌면 브라우저가 실행을 거부합니다.
- **로그인 코드 요청에 Cloudflare Turnstile 확인이 붙습니다.** sprag.io/team 과 sprag.io/ops 의 코드 보내기 버튼 위에 확인 위젯이 나오고 팀 서버는 확인을 거치지 않은 요청을 거절합니다. 스크립트가 등록된 오너 주소로 1분마다 코드를 요청해 프로젝트의 시간당 메일 한도를 비우거나 아무 주소로 계정을 만드는 일을 막습니다. `sprag team create` 는 코드를 직접 요청하지 않고 sprag.io/team 을 열어 거기서 요청하게 한 뒤 메일로 받은 코드를 터미널에서 받습니다.
- **상태줄 맨 위에 effort 가드 줄이 섭니다.** `🔬🔥 Effort guard ×3 since 11/1  |  sonnet medium→high`처럼 effort 없이 Sonnet에 보낸 위임을 high로 올린 횟수를 라우팅 절감과 같은 초기화 기준으로 셉니다. 전에는 `🔬 Effort saved $0.45`로 절감 줄 아래에 있었는데 상향은 토큰을 더 쓰는 쪽이고 막는 것은 아무도 다시 돌릴 줄 모르는 조용한 오답이라 금액을 붙이는 것이 틀렸습니다. 그래서 금액을 떼고 횟수만 적으며 품질 장치답게 절감 위에 둡니다. 한 줄 배치에서는 `🔬↑N` 칩이고 `sprag saved`는 상향한 위임의 실행 비용을 덧붙입니다.
- **팀 줄이 지금 몇 %인지 말하고 혼자일 때는 왜 움직이지 않는지 적습니다.** 팀 서버가 점수 백분위를 보내지 않아도 순위에서 읽어 냅니다. 사무실 페이지와 같은 계산이라 n명 중 r위는 (n−r)/(n−1)이고 다음 등급까지 몇 명을 앞질러야 하는지도 같은 식으로 셉니다. 그래서 `지금 75%, 2%p 더 오르면 🐆 치타 (1명 앞지르기)`가 서버 갱신과 무관하게 나옵니다. 순위에 혼자면 백분위가 50%에 고정되어 🐱 고양이에 머물므로 `지금 50%, 혼자라 고정 · 동료가 참여하면 순위 시작`이라고 적고 `sprag team status`의 다음 등급 줄도 같은 사정을 설명합니다. 늑대 이상 여섯 종의 위임 비율 조건은 서버가 중앙값을 보내야 판정되므로 그때까지는 조건만 적습니다.
