
- **A session on a model that is 1M by default counts a 1M window before its first statusline report.** Opus 5.5 picked as `opus` or `claude-opus-5-5` has no `[1m]` in its name, so until the statusline reported the window the session was counted as 200k and the 80% briefing fired at about 160k, some 16% of the real window. The session now borrows the window another session's statusline reported for the same model, and an alias such as `opus` follows the newest report of its family (#14).

## 한국어

- **1M이 기본인 모델의 세션이 첫 상태줄 보고 전에도 1M 창으로 셉니다.** Opus 5.5를 `opus`나 `claude-opus-5-5`로 고르면 이름에 `[1m]`이 없어서 상태줄이 창 크기를 보고하기 전까지 200k로 셌고 80% 브리핑이 실제 창의 16%쯤인 160k에서 떴습니다. 이제 다른 세션의 상태줄이 같은 모델로 보고한 창을 빌려 씁니다. `opus` 같은 별칭은 가장 최근에 보고된 같은 계열 모델을 따릅니다(#14).
