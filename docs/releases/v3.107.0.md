- **Work that ends in a judgement now goes up to Opus instead of down to a cheaper model.** Improvement reviews, audits, root-cause diagnosis, research that needs searching and lookups that must conclude something does not exist stay on the main model. If the main model still hands one to Sonnet or Haiku, the delegation guard runs it on Opus at effort high and counts it on the statusline as `model↑N`. Replaying ten such jobs, Sonnet high reached the Opus conclusion once and Opus high five times.
- **When the main session runs at low or medium effort, sprag suggests handing the judgement part to Opus at high.** The statusline records each session's effort, and a judgement request on a low-effort session gets one hint per session. On ten judgement jobs, dropping effort from high to medium cut same conclusions from 8 to 4. `sprag routing effort-hint off` turns it off.
- **Past 70% of a usage limit, sprag offers to widen delegation until that window resets.** If you agree, `sprag routing relax` widens it and switches back by itself when the window resets; `sprag routing relax off` ends it early.
- **Haiku now gets only pasted logs, reading named documents and translation.** Lookups, checks and command runs go to Sonnet. The 15 jobs the new rule hands off came out same 12, partial 3, unusable 0, the level Opus reaches against itself, at 64% less than running them on Opus.
- **A Sonnet session asking for judgement work gets one hint per session to use Opus.** Requests that only ask for an action, such as a deploy or a merge, get none.
- **`sprag secrets` finds secrets in Claude Code's list of approved commands.** It answers Apiiro's finding (5 November) that commands approved with "don't ask again" sit in settings.local.json with their passwords and tokens, 1,122 such files public on GitHub. It scans the home and project settings, reports the matching entries masked and whether git tracks the file, and `sprag secrets fix` backs the file up and removes them. A session start mentions a hit once per file change.
- **sprag redacts secrets in the files it writes too.** The 80-character prompt excerpts kept as rule examples are redacted before they are cut, settings and CLAUDE.md backups are readable by you alone (0600), and doc2md copies older than 30 days and stale temp files are swept once a day.
- **A delegation prompt with a long path in it is still recognised as judgement work.** A live session handed off a security review whose full directory path hid it from the check; paths now shrink to one token before the check runs.
- **sprag.io/proof shows how it measures and where the numbers stop.** It now carries the causes of eight partial marks, when to go up, what lower effort does, the jobs the new rule hands off, and grader variance (96% of 78 reports kept their verdict).

## 한국어

- **판단이 결론인 일은 싼 모델로 넘기지 않고 Opus로 올립니다.** 개선점 검토, 감사, 원인 진단, 검색이 필요한 조사, 무엇이 "없다"고 단정하는 조회는 메인에 남깁니다. 메인이 그래도 Sonnet이나 Haiku로 넘기면 위임 가드가 Opus effort high로 바꿔 실행하고 상태줄에 `model↑N`으로 셉니다. 판단형 10건을 다시 돌렸을 때 Sonnet high는 Opus와 같은 결론을 1건 냈고 Opus high는 5건 냈습니다.
- **메인 세션의 effort가 낮으면 판단 부분을 Opus high에 맡기라고 안내합니다.** 상태줄이 세션의 effort를 기록하고, 판단형 요청인데 effort가 low나 medium이면 세션당 한 번 안내가 나갑니다. 판단형 10건에서 effort를 high에서 medium으로 낮추면 같은 결론이 8건에서 4건으로 줄었습니다. `sprag routing effort-hint off`로 끌 수 있습니다.
- **사용량이 한도의 70%를 넘으면 그 창이 끝날 때까지만 위임을 넓히자고 제안합니다.** 동의하면 `sprag routing relax`가 위임 범위를 넓히고 창이 초기화되면 저절로 원래대로 돌아옵니다. `sprag routing relax off`로 일찍 끝낼 수 있습니다.
- **Haiku에는 붙여넣은 로그, 정해진 문서 읽기, 번역만 넘깁니다.** 조회, 점검, 명령 실행은 Sonnet이 맡습니다. 새 규칙으로 넘긴 15건은 같은 결론 12건, 부분 3건, 못 씀 0건이었습니다. Opus를 두 번 돌려 비교한 수준과 같고 비용은 Opus 직접보다 64% 적었습니다.
- **Sonnet 세션에서 판단형 요청이 오면 Opus를 권하는 안내가 세션당 한 번 나옵니다.** 배포나 머지처럼 행동만 담은 요청에는 나오지 않습니다.
- **`sprag secrets` 가 Claude Code 승인 목록에서 비밀 값을 찾아 줍니다.** "다시 묻지 않기"로 승인한 명령이 비밀번호와 토큰째 settings.local.json 에 남아 공개 GitHub 파일 1,122개에서 발견됐다는 조사(Apiiro, 11월 5일)에 대응합니다. 홈과 프로젝트의 설정 파일을 검사해 값은 가린 채 걸린 항목과 git 추적 여부를 알리고 `sprag secrets fix` 가 원본을 백업한 뒤 그 항목을 지웁니다. 세션을 시작할 때 파일이 바뀌었으면 한 번 알립니다.
- **sprag가 쓰는 파일에서도 비밀 값을 가립니다.** 룰 예시로 남기는 80자 프롬프트 발췌는 자르기 전에 토큰과 비밀번호를 가리고, 설정과 CLAUDE.md 백업은 본인만 읽을 수 있게(0600) 저장합니다. 30일 지난 doc2md 사본과 남은 임시 파일은 하루에 한 번 지웁니다.
- **긴 경로가 섞인 위임 지시문도 판단형으로 알아봅니다.** 실제 세션에서 절대 경로가 들어간 보안 검토 위임을 놓친 일이 있었고, 경로를 짧은 표지로 바꾼 뒤 판정합니다.
- **sprag.io/proof 가 측정 방법과 한계를 함께 보여 줍니다.** 부분 판정 8건의 원인, 올려야 할 때, effort를 낮췄을 때, 새 규칙으로 넘긴 일, 채점자 편차(78건 중 96% 같은 판정)를 실었습니다.
