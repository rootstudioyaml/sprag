- **sprag's statusline now shows inside Orca.** When the statusLine slot is empty, Orca writes its own command there, and that command prints nothing. On a machine that had Orca first, `sprag install` took it for the user's own statusline and skipped, so no terminal drew a line. The installer now recognises Orca's command and merges without asking: Orca's command keeps running underneath sprag's, so Orca's usage display stays fed, and uninstall puts it back.
- **`sprag panel` gives hosts that never draw the statusline a live copy.** Hosts that run Claude Code through the Agent SDK, such as T3 Code, never run the statusLine command. Run `sprag panel` in the host's integrated terminal and it follows the newest session of that project, redrawing the statusline every 5 seconds and repainting only when the text changes; `--once` prints a single frame. The Codex panel, `sprag panel --agent codex`, is unchanged.

## 한국어

- **Orca 안에서도 sprag 상태줄이 보입니다.** Orca는 statusLine 칸이 비어 있으면 아무것도 출력하지 않는 자기 명령을 넣어 둡니다. 그래서 Orca를 먼저 설치한 컴퓨터에서는 sprag 설치가 그 명령을 사용자의 상태줄로 보고 건너뛰었고 어느 터미널에도 줄이 그려지지 않았습니다. 이제 설치가 Orca 명령을 알아보고 묻지 않고 합칩니다. Orca 명령은 sprag 아래에서 계속 돌아 Orca의 사용량 표시도 유지되고 언인스톨하면 원래대로 돌아갑니다.
- **`sprag panel` 이 상태줄을 그리지 않는 호스트에서 실시간 사본을 띄웁니다.** T3 Code처럼 Agent SDK로 Claude Code를 실행하는 호스트는 statusLine 명령을 실행하지 않습니다. 그 호스트의 내장 터미널에서 `sprag panel` 을 실행하면 해당 프로젝트의 가장 최근 세션을 따라가며 5초마다 상태줄을 다시 그립니다. 내용이 바뀔 때만 화면을 갱신하고 `--once` 는 한 프레임만 출력합니다. Codex용 `sprag panel --agent codex` 는 그대로입니다.
