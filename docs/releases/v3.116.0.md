- **Savings rate and delegation ratio are now computed on spend since install.** On first join the CLI uploads the last 30 days of spend, so spend from before sprag was installed sat in the denominator and pulled both rates down; each machine now counts from the earlier of its join date and its first delegation, which moved one organisation's 30-day savings rate from 0.61% to 2.37% (spend totals still cover the whole range, and server migration 20261111000100 supplies the start dates).
- **The organisation overview gains a savings rate card.** It sits next to the savings card with a line naming the spend it divides by, the delegation ratio card carries the same line, and the savings rate column in the team savings panel is now labelled "Savings rate (since install)".
- **The operator town uses the same basis.** Signboard gauges, rooftop flags, the HUD total and the team table in the drawer compute savings rate and delegation ratio on spend since install, as does the company delegation figure in the office HUD; personal delegation ratios and animal grades are unchanged.

## 한국어

- **절감률과 위임 비율을 설치 이후 지출로 계산합니다.** 처음 팀에 참여할 때 CLI가 최근 30일 지출을 올리므로 sprag를 깔기 전 지출까지 분모에 들어가 비율이 낮게 나왔습니다. 이제 컴퓨터마다 참여일과 첫 위임 기록일 중 이른 날부터의 지출로 나눕니다. 운영 데이터에서 한 조직의 30일 절감률이 0.61%에서 2.37%로 바뀌었습니다. 지출 금액은 이전처럼 기간 전체를 보여 줍니다. 서버 마이그레이션 20261111000100이 컴퓨터별 시작일을 보냅니다.
- **조직 개요에 절감률 카드가 생겼습니다.** 절감 카드 옆에 절감률이 나오고 그 아래에 어느 지출을 기준으로 삼았는지 적습니다. 위임 비율 카드에도 같은 기준 문구가 붙고 팀별 절감 패널의 절감률 열은 "절감률(설치 후)"로 이름을 바꿨습니다.
- **운영자 타운의 절감률도 같은 기준을 씁니다.** 간판 게이지, 옥상 깃발, HUD 합계와 서랍의 팀 표가 모두 설치 이후 지출로 절감률과 위임 비율을 계산합니다. 사무실 HUD의 회사 위임 비율도 같습니다. 개인 위임 비율과 동물 등급은 바뀌지 않았습니다.
