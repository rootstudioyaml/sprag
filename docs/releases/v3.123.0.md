- **The public site has a new design.** Colors come down to three, white, black and a Very Peri accent, and every corner is square. The home page unfolds five steps as you scroll while a Sprag rotor, remodeled in Blender, turns beside them. Light mode is the default and the header switch picks dark mode. This is an outside contribution (#19).
- **The site honors reduced motion.** When the browser asks for `prefers-reduced-motion`, nothing moves and the intro is a single screen. The same layout appears if the scroll script fails to load. Lenis, which smooths wheel scrolling, loads with an SRI hash.

## 한국어

- **공개 사이트를 새로 디자인했습니다.** 색은 흰 바탕과 검정, 포인트 색 Very Peri 세 가지로 줄였고 모서리는 모두 직각입니다. 홈은 스크롤을 내리면 다섯 단계가 차례로 펼쳐지고 그동안 Blender로 다시 만든 Sprag 회전체가 돕니다. 밝은 모드가 기본이며 헤더의 전환 버튼으로 어두운 모드를 고를 수 있습니다. 외부 기여로 들어온 작업입니다(#19).
- **모션 감소 설정을 지킵니다.** 브라우저가 `prefers-reduced-motion`을 요청하면 아무것도 움직이지 않고 인트로는 화면 한 장으로 끝납니다. 스크롤 효과 스크립트를 불러오지 못해도 같은 화면이 나옵니다. 휠 스크롤을 부드럽게 하는 Lenis는 SRI 해시를 붙여 불러옵니다.
- **팀 콘솔과 운영 화면의 차트가 밝은 모드에서도 읽힙니다.** 어두운 모드는 기존 차트 색을 그대로 씁니다. 밝은 모드는 같은 색조를 어둡게 내려 흰 바탕 대비 3:1 이상, 막대 위 금액 글자는 4.5:1 이상으로 맞췄습니다. 복구된 좌석을 나타내는 민트색은 1.42:1이던 대비가 3.12:1로 올라갔습니다.
