- **A compact level now trims how much the statusline shows.** `sprag mode compact=2` folds the headline lines such as Routing saved and the team line into chips and keeps only the warning, rate-limit, Ctx, TTL, model and routing chips on at most two lines. `compact=3` keeps only the warning, rate-limit, Ctx and TTL chips on one line. `compact=0` and `compact=1` are today's long and short labels, and `--compact-level N` tries a level for one run.
- **settings.json saved with a UTF-8 BOM is read again.** Windows PowerShell writes settings.json with a leading BOM, which sprag failed to parse, so it skipped hook registration. Every settings.json read now strips one leading BOM. A missing `~/.npmrc` or a claude binary absent from the hook PATH is normal and no longer goes to the diagnostics log.
- **The Korean lint no longer flags the `|` inside an Obsidian wikilink.** `[[note|label]]` is checked as the label the reader sees, so the label's style is still linted. A user report showed 6,244 false hits across a 1,913-file vault. A Bash redirect that only copies existing text, such as `cat` or `git log`, no longer counts as new writing.
- **The diagnostics log says why a model stayed unknown.** It records the reason per raw model id, such as a missing profile id or a model not yet learned, with the gateway table state, and masks the AWS account id. Pricing is unchanged.

## 한국어

- **상태줄에 보이는 양을 compact 레벨로 줄일 수 있습니다.** `sprag mode compact=2`는 Routing saved와 팀 같은 헤드라인 줄을 칩으로 접고 경고, 사용량, Ctx, TTL, 모델, 라우팅 칩만 두 줄 안에 남깁니다. `compact=3`은 경고, 사용량, Ctx, TTL 칩만 한 줄에 남깁니다. `compact=0`과 `compact=1`은 지금의 긴 라벨과 짧은 라벨이고 `--compact-level N`으로 한 번만 바꿔 볼 수 있습니다.
- **BOM이 붙은 settings.json도 읽습니다.** Windows PowerShell은 settings.json 앞에 BOM을 붙여 저장하는데 sprag는 이 파일을 읽지 못해 훅 등록을 건너뛰었습니다. 이제 settings.json을 읽을 때마다 앞의 BOM 하나를 떼어 냅니다. `~/.npmrc`가 없거나 훅 PATH에 claude가 없는 흔한 경우는 진단 로그에 더 남기지 않습니다.
