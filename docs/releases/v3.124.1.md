- **The token size of an unknown-model price miss is no longer masked.** The first diagnostics from 3.124.0 arrived as `tokens=[redacted]`, because the secret masker that runs before an upload read `tokens=0` and `tokens=100k+` as a secret. The label is now `size=`, and a test runs all four buckets through the masker unchanged.

## 한국어

- **모델이 unknown으로 남은 가격 누락의 토큰 규모가 가려지지 않습니다.** 3.124.0에서 처음 올라온 진단 로그는 `tokens=[redacted]`였습니다. 진단 로그를 올리기 전에 도는 비밀값 마스커가 `tokens=0`과 `tokens=100k+`를 비밀값으로 읽었기 때문입니다. 라벨을 `size=`로 바꿨고 네 구간이 모두 마스커를 그대로 통과하는지 테스트로 확인합니다.
