- **sprag now asks whether to register a ratchet rule when the same error comes back.** The candidate detector only ran from a hook that had to be registered separately with `--install-hook`, so a plain `sprag install` never showed the `🅷⚠ ratchet?` chip. The tool hook that every install registers now runs it, and when a candidate appears the model asks once, after the current task, with a draft rule and the scope to register it in.
- **An error that recurs in a later session now counts as a candidate.** Detection used to need the same error twice within the last 30 lines of one session. Replaying 30 days of one machine's sessions (1,043) found 30 error shapes that recurred across two or more sessions, against 6 sessions in 14 days with a repeat inside one session. Shapes are kept for 30 days in `ratchet-seen.json` as hashes with paths and numbers stripped, and no error text is stored.
- **A single error is no longer counted as a repeat.** Claude Code copies tool results into the API request lines of a transcript and the detector counted the copy. Tool calls the user declined and bare `Exit code` results are no longer candidates either.
- **The `no-evidence` warning no longer fires wrongly for `--install-hook` users.** A hook record between a tool call and its result kept the analyzer from counting the result as evidence. Over 14 days of sessions (961) the share of tool calls that raised the warning went from 10.4% to 0.1%.
- Set `"ratchetFollowUp": false` in config.json to turn off the question alone and keep the statusline chip. `sprag harness off` turns the detection off altogether.

## 한국어

- **같은 오류가 다시 나오면 래칫 룰로 등록할지 묻습니다.** 지금까지 후보 감지는 `--install-hook`으로 따로 등록하는 훅에서만 돌았습니다. `sprag install`만 한 사용자에게는 `🅷⚠ ratchet?` 칩이 뜨지 않았습니다. 이제 기본 설치되는 도구 훅이 감지합니다. 후보가 생기면 모델이 하던 작업을 마친 뒤 룰 초안과 등록 범위를 함께 묻고 같은 오류는 한 번만 안내합니다.
- **다른 세션에서 났던 오류가 재발해도 후보가 됩니다.** 이전 감지는 한 세션의 최근 30줄 안에서 같은 오류가 두 번 나와야 했습니다. PC 한 대의 30일 기록 1,043세션을 재생해 보니 두 세션 이상에서 재발한 오류 모양이 30개였고 세션 안 반복은 14일에 6세션뿐이었습니다. 오류 모양은 경로와 숫자를 지운 뒤 해시로 바꿔 `ratchet-seen.json`에 30일 동안 남기며 오류 문구는 저장하지 않습니다.
- **한 번 난 오류를 반복으로 세던 오탐을 고쳤습니다.** Claude Code가 트랜스크립트에 남기는 API 요청 기록 줄에 같은 오류가 복제돼 있어서 감지기가 이를 두 번으로 셌습니다. 사용자가 거절한 도구 호출과 내용 없는 `Exit code` 결과도 이제 후보에서 빠집니다.
- **`--install-hook` 사용자에게 `no-evidence` 경고가 잘못 뜨던 문제를 고쳤습니다.** 도구 호출과 결과 사이에 훅 기록 줄이 끼면 분석기가 결과를 증거로 세지 못했습니다. 14일 기록 961세션에서 이 경고가 뜨는 도구 호출 시점이 10.4%에서 0.1%로 줄었습니다.
- 등록 안내만 끄려면 config.json에 `"ratchetFollowUp": false`를 넣습니다. 상태줄 칩은 계속 나옵니다. `sprag harness off`는 감지 전체를 끕니다.
