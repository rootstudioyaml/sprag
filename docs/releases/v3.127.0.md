- **An implementation handed to a lower model no longer gets an output-token cap.** The cap meant for lookups (6,000 to 8,000 tokens) was attached to implementation hand-offs too, and a worker could stop before it wrote its tests. Replaying ten real implementation hand-offs showed 13,000 to 39,000 output tokens each. The delegation guard now recognises an implementation hand-off and appends stop conditions instead of a number: the completion criteria hold, the same failure repeats twice, or the design does not fit the code. A tool-call budget written in the prompt still applies.
- **The specification for an implementation hand-off now has nine items.** The goal and its reason, the settled design, the files to change and what stays untouched, what else must change with it, the repository conventions, completion criteria, test commands, the report format and the recommended model. The main model finds the other callers and the conventions itself before delegating. Of 118 real hand-off prompts, 43% stated completion criteria.
- **The main model checks the diff of a handed-off implementation even when its tests pass.** Seventeen implementations were run on Sonnet and on Opus and graded. Of the seven handed-off results that needed fixing, five had passed their tests. In server and CLI code the usual miss was a hidden coupling, such as a list that a test enforces. The worker now runs every command the task names and puts the evidence the task asks for in its report.
- The worker bodies and the ratchet preset also went out as server preset v5, so a CLI that has not been upgraded receives them within a day.
- The Codex implementation hint no longer states an 8,000-token cap either.
- The proof lab (sprag.io/proof) now opens with three results: reading a document as Markdown took 89% fewer tokens, handed-off code writing cost 58% less, and handed-off lookups and command runs cost 56% less. The cases and tables fold open below.
- The plan videos and the README previews now show the town at night, with the year-end dressing and the big ginkgo tree.
