- **Several delegations started at once now each get their guidance exactly once.** In auto mode the queue that holds the guidance was a single file, so two hooks running together could overwrite each other's entry and a subagent started without its guidance. Each entry now has its own file and is claimed by renaming it, so nothing is lost or delivered twice without a lock.
- **The relax offer to widen delegation now reaches each session once.** It used to go out once per limit window across all sessions, so if that session's model did not pass it on, nobody saw it until the window reset.
- Plugin agents (named `plugin:agent`) were checked in a live session to receive the same guidance in auto mode.
