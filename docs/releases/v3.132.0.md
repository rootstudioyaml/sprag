- **macOS gets a menu bar app, Sprag Bar.** An animal in the menu bar runs to the whole machine's CPU load, with the figure beside it. A click opens every running Claude Code and Codex session, who is using the CPU, memory and GPU, account limits, settings and ratchet rules. It starts when a session starts, and `sprag bar off` turns it off. The app is not shipped as a binary: sprag compiles its Swift source on your Mac once, and again only when a release changes that source. On a Mac without the Xcode command line tools it does not appear, and `sprag bar status` says why.
- **A dashboard window shows sessions and machine resources on one screen.** Session tiles are grouped by project and show the tool and the programs running now. Each line in the largest-users lists for CPU, memory and GPU names the session, the program in it and what that session is doing. Processes left running by sessions that have ended are listed apart and can be stopped from a checklist: apps, virtual machines and databases cannot be ticked, and a process with an open connection starts unticked.
- **Fixed a context warning that arrived after the compaction it warned about.** The notice that the context had passed 95% of the compaction window was relayed at the end of the answer, so in a turn with many tool calls it came out after compaction had already run. It is now relayed in the first line of the answer. Once compaction runs, an earlier warning is treated as out of date and only a one-line note that compaction ran is shown.
- `sprag bar` prints each running session's model, effort, context, cost, CPU and memory with the account limits. It takes `--json`, `--detail`, `--settings` and `--rules`, and `--swiftbar` prints SwiftBar or xbar output.
- A member with no upload for 48 hours stays in the team ranking, which fixes most of an organization showing as ghosts on a Monday morning. A ghost now means uploads are switched off or there has been no contact for 30 days.

## 한국어

- **macOS에 메뉴 막대 앱 Sprag Bar가 생겼습니다.** 메뉴 막대의 동물이 기기 전체 CPU 사용률에 맞춰 달리고 옆에 그 값이 나옵니다. 누르면 실행 중인 Claude Code와 Codex 세션, CPU와 메모리와 GPU를 누가 쓰는지, 계정 한도, 설정, 래칫 규칙이 열립니다. 세션이 시작될 때 자동으로 뜨고 `sprag bar off`로 끕니다. 앱은 실행 파일로 배포하지 않습니다. 사용자의 Mac에서 Swift 소스를 한 번 컴파일하고 릴리스가 그 소스를 바꿨을 때만 다시 컴파일합니다. Xcode 명령줄 도구가 없는 Mac에서는 뜨지 않고 `sprag bar status`가 이유를 알려 줍니다.
- **대시보드 창이 세션과 기기 자원을 한 화면에 보여 줍니다.** 프로젝트별로 묶인 세션 타일에 지금 도는 도구와 프로그램이 나옵니다. CPU, 메모리, GPU의 많이 쓰는 곳 목록은 줄마다 어느 세션의 어떤 프로그램인지와 그 세션이 하는 일을 함께 적습니다. 끝난 세션이 남긴 프로세스는 따로 모아 보여 주고 골라서 끌 수 있습니다. 앱과 가상 머신과 데이터베이스는 선택할 수 없고 연결이 열려 있는 프로세스는 기본 선택에서 빠집니다.
- **컨텍스트 경고가 압축이 끝난 뒤에 전달되던 문제를 고쳤습니다.** 압축 창의 95%를 넘었다는 안내가 답변 맨 끝에 전달되어서 도구 호출이 이어지는 턴에서는 이미 압축된 뒤에 나왔습니다. 이제 답변 첫 줄에 나옵니다. 압축이 돌면 그 전에 나간 경고를 지난 정보로 처리하고 압축이 돌았다는 한 줄만 알립니다.
