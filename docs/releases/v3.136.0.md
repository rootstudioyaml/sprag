- **대시보드가 마지막 크기와 위치를 기억하고 다른 창 위에 고정할 수 있습니다.** 제목 막대의 핀 단추나 윈도우 메뉴의 "항상 위에 두기"로 고정합니다. 작게 줄여 화면 구석에 두면 다른 작업을 하면서 세션을 볼 수 있습니다.
