- **Sprag Bar can be started again from Spotlight or Launchpad after you quit it.** Starting the app now writes `~/Applications/Sprag Bar.app`, and opening it runs `sprag bar on`. Until now a quit app came back only with the next session or a command typed in a terminal. The launcher wears the same animal icon as the Dock, `sprag bar off` and uninstall remove it, and an app of the same name that sprag did not write is left alone.
- **Sprag Bar and `sprag bar` name each session after what you last asked it.** Claude Code names a session after its folder plus a number, like `sprag-6b`, so sessions in the same folder looked alike. The first line of the last prompt is now the name, and when that prompt is shorter than 5 characters ("ok", "approved") or starts with `/`, the conversation title Claude Code made is used instead. A name given with `/rename` is kept. The old name stays in the tooltip and rows keep sorting by it, so a new prompt does not move a row.
- **Going to a session works when the terminal's windows are minimized to the Dock.** "Go to session" only brought the terminal app forward, so with every window in the Dock nothing changed on screen. When the app has no window on screen it now gets the same reopen event as a Dock click, which restores the window without asking for any permission. A minimized window stays in the Dock while another window of the same app is on screen.

## 한국어

- **Sprag Bar를 끈 뒤 Spotlight나 Launchpad에서 다시 켤 수 있습니다.** 앱이 뜰 때 `~/Applications/Sprag Bar.app`을 만들고 이 앱을 열면 `sprag bar on`이 실행됩니다. 지금까지는 앱을 끄면 다음 세션을 시작하거나 터미널에서 명령을 쳐야 다시 떴습니다. 실행기는 Dock 아이콘과 같은 동물 아이콘을 쓰고 `sprag bar off`나 삭제 명령이 지웁니다. 같은 이름의 다른 앱이 있으면 건드리지 않습니다.
- **Sprag Bar와 `sprag bar`가 세션을 마지막으로 시킨 일로 보여 줍니다.** Claude Code가 붙이는 이름은 `sprag-6b`처럼 폴더 이름에 번호를 붙인 것이라 같은 폴더의 세션끼리 구별되지 않았습니다. 이제 마지막 프롬프트의 첫 줄을 이름으로 씁니다. "승인완료"처럼 5자보다 짧거나 `/`로 시작하는 프롬프트일 때는 Claude Code가 만든 대화 제목으로 대신합니다. `/rename`으로 붙인 이름은 그대로 둡니다. 원래 이름은 툴팁에 남고 행 순서도 원래 이름을 따르므로 프롬프트가 바뀌어도 줄이 움직이지 않습니다.
- **Dock에 내려 둔 터미널로도 세션으로 이동합니다.** "세션으로 이동"은 터미널 앱을 앞으로 가져오기만 해서 창이 모두 Dock에 내려가 있으면 화면이 바뀌지 않았습니다. 이제 보이는 창이 없으면 Dock 아이콘을 누른 것과 같은 신호를 보내 창을 펼칩니다. 권한은 묻지 않습니다. 같은 앱의 다른 창이 화면에 있으면 내려 둔 창은 그대로입니다.
