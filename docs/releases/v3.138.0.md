- **Going to a session opens its own tab in Terminal.app and iTerm2 too.** Only Orca could pick the exact tab so far, and Terminal.app and iTerm2 only came forward, so with several tabs open another tab was showing. The tab whose tty matches the session is now selected, and its window is restored and raised. macOS asks once for the Automation permission, and if it is refused the app is brought forward as before.
- **The top of the menu bar panel is no longer cut off.** The content's height limit was set once at launch from the main screen, so on a shorter screen holding the menu bar the content grew taller than the window and lost its top. The limit now follows the menu bar's screen every time the panel is placed, and a page that still overflows loses its bottom, so the header with the back and menu buttons always shows.

## 한국어

- **Terminal.app과 iTerm2에서도 세션이 열린 탭으로 바로 갑니다.** 지금까지 정확한 탭을 고르는 것은 Orca뿐이었고 Terminal.app과 iTerm2는 앱만 앞으로 와서 탭을 여러 개 열어 두면 다른 탭이 보였습니다. 이제 세션의 tty와 같은 탭을 골라 그 창을 펼치고 맨 앞으로 올립니다. 처음 한 번 macOS가 자동화 권한을 묻습니다. 거절하면 지금처럼 앱만 앞으로 가져옵니다.
- **메뉴 막대 패널의 위쪽이 잘리지 않습니다.** 패널 안쪽 내용의 최대 높이를 앱이 시작될 때 주 화면 기준으로 한 번만 정해서 메뉴 막대가 있는 화면이 그보다 낮으면 내용이 창보다 커졌고 넘친 위쪽이 잘렸습니다. 이제 패널을 놓을 때마다 메뉴 막대가 있는 화면의 높이로 다시 정합니다. 그래도 넘치면 아래쪽을 줄이므로 뒤로 가기와 메뉴 단추가 있는 머리 줄은 늘 보입니다.
