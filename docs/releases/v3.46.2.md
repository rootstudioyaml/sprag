- **The npm page now reads in one language.** The README alternated English and
  Korean section by section, so either reader skipped half of it. English stays in
  `README.md`, Korean moved to `README.ko.md`, and the npm badge points at
  `sprag-cli` instead of the old package name.
- **Each guide is now two files, one per language.** The seven guides under
  `docs/` (install, commands, gateways, harness, Korean style, statusline,
  not-a-router) mixed both languages in a single file; every one now has an
  English file and a `.ko.md` sibling, so a link takes you to one document you can
  read straight through.
- **The Korean-generating script is gone.** `scripts/sync-readme-ko.mjs` ran from
  `prepublishOnly` and regenerated the README's Korean sections mechanically,
  which would now overwrite hand-edited prose. The script and both npm scripts
  that called it (`prepublishOnly`, `sync:ko`) have been removed.

This release changes documentation only; no runtime behaviour differs from
v3.46.1.

## 한국어

- **npm 페이지의 README 가 한 언어로 읽힙니다**: README 본문에 영어와 한국어가 번갈아 들어 있어서, 어느 쪽 독자든 자기가 읽지 않는 절을 절반씩 건너뛰어야 했습니다. 영어 본문만 README 에 남기고 한국어 본문은 `README.ko.md` 로 옮겼습니다. 패키지 설명이 곧 npm 페이지이므로 이 정리는 문서 작업이면서 배포 대상입니다. 함께 깨져 있던 npm 배지도 `sprag-cli` 를 가리키도록 고쳤습니다.
- **가이드 문서가 언어별 파일로 갈라졌습니다**: `docs/` 의 일곱 개 가이드(설치, 명령, 게이트웨이, harness, 한국어 스타일, statusline, not-a-router)가 한 파일 안에서 두 언어를 섞고 있었습니다. 각각 영어 파일과 `.ko.md` 파일로 나누어, 링크를 따라온 독자가 자기 언어의 문서 하나만 읽으면 되도록 했습니다.
- **한국어 생성 스크립트를 없앴습니다**: `scripts/sync-readme-ko.mjs` 가 `prepublishOnly` 에서 돌면서 README 의 한국어 절을 기계로 다시 만들고 있었는데, 한국어 본문이 독립 파일이 된 지금은 이 스크립트가 손으로 다듬은 문장을 되돌립니다. 스크립트와 `prepublishOnly`·`sync:ko` 항목을 모두 제거했습니다.
