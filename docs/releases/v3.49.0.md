- **The statusline now shows the effort level the session is running at.** It sits right after the model chip, as `🔬 max`, because the same model answers differently at `low` and at `max` and the pair reads as one glance: who is answering, and how hard. The default level `high` and the levels above it share the model chip's magenta, while levels below the default recede to gray — spending less is a choice, not something to warn about.
- The chip simply does not render for models that carry no effort setting, or on Claude Code builds older than the field itself. Claude Code only puts the level in the statusline payload when the model has one, so an absent value means there is nothing to show rather than something gone wrong.
- The glyph is 🔬 rather than 🎚. Both 🎚 and 🎛 are East Asian Width N, so they are drawn two cells wide while being counted as one, and the whole line shifts sideways on every repaint. Narrow mode uses `▲`.
- The effort level is never written to the snapshot cache. That cache exists so the table view, which is given no stdin, can still show the model and rate limits — but a level the user has since changed would be worse there than no chip at all.
- The tone lookup is guarded with `Object.hasOwn`. The level is a string off a JSON payload, so `constructor` or `__proto__` would resolve through `Object.prototype` to a function, and since that value is truthy the default-tone fallback could not catch it before it was interpolated into the line.

## 한국어

- **statusline 이 세션의 effort 레벨을 보여 줍니다.** 모델 칩 바로 뒤에 `🔬 max` 처럼 붙습니다. 같은 모델이라도 `low` 와 `max` 에서 답이 달라지므로, 어떤 모델이 답하는지와 얼마나 힘을 주어 답하는지를 한눈에 보도록 두 칩을 나란히 두었습니다. 기본값인 `high` 와 그 위의 `xhigh`·`max` 는 모델 칩과 같은 자홍색 계열이고, 기본값보다 낮은 레벨은 회색으로 물러납니다. 낮은 레벨은 비용을 덜 쓰는 선택이므로 경고할 일이 아닙니다.
- effort 설정이 없는 모델이나 이 필드보다 오래된 Claude Code 에서는 칩이 그냥 나오지 않습니다. Claude Code 가 해당 모델일 때만 값을 실어 보내므로, 값이 없다는 것은 보여 줄 것이 없다는 뜻이지 오류가 아닙니다.
- 아이콘은 🎚 대신 🔬 를 씁니다. 🎚 과 🎛 은 East Asian Width 가 N 이라 두 칸으로 그려지면서 한 칸으로 계산되어, 다시 그릴 때마다 줄 전체가 좌우로 흔들립니다. narrow 모드에서는 `▲` 입니다.
- effort 레벨은 캐시에 저장하지 않습니다. 캐시는 stdin 이 들어오지 않는 표 화면에서 값을 대신 보여 주려고 두었는데, 사용자가 이미 바꾼 레벨이 거기 남아 있는 편이 칩이 없는 것보다 나쁩니다.
- 색상표를 이름으로 찾을 때 `Object.hasOwn` 으로 감쌌습니다. 레벨은 JSON 에서 온 문자열이므로 `constructor` 나 `__proto__` 가 들어오면 Object.prototype 을 타고 함수가 잡히고, 그 값은 참이라서 기본값 대체로도 걸러지지 않은 채 줄에 그대로 박힙니다.
