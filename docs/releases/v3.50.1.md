- **Publish, merge and root-cause questions no longer get a delegation hint.** The prompt-time hint read "npm 퍼블리시 진행하자" as a command to run and "번역이 안 되는 이유를 확인해보자" as translation work, and told the session to hand both to a cheaper model. Irreversible actions and root-cause analysis belong on the top tier, so the Korean words for publish, release, merge and "the reason" now count as escalation. The word for merge, `머지`, also appears inside `나머지` ("the rest"), so it is accepted only when the preceding character is not `나`; that false match occurred 7 times in 1,276 real prompts.
- **Implementation requests stay quiet even when they mention running or checking something.** Sentences like "install this and make it configure itself" or "check the feedback and make an app icon too" were scored as run or check work on the strength of `install` and `check`, but what they ask for is a code change. At prompt time there are no tool calls to reveal that, so the wording has to: when an implementation verb is present the hint is withheld. The offline scan already excludes such episodes from their tool mix and is unchanged.
- Replaying both versions over the same 1,276 prompts, hints fell from 395 to 365; of the 30 that disappeared, 26 had pointed delegation at the wrong kind of work, and none appeared that were not there before. Candidates and rules from the offline scan are unchanged.

## 한국어

- **퍼블리시·머지·원인 질문은 위임 힌트에서 빠집니다.** 프롬프트 시점 힌트가 "npm 퍼블리시 진행하자"를 명령 실행으로, "번역이 안 되는 이유를 확인해보자"를 번역 작업으로 읽어 하위 모델에 보내라고 권하고 있었습니다. 되돌릴 수 없는 작업과 원인 분석은 상위 모델이 맡아야 하므로 `퍼블리시`·`릴리스`·`머지`·`이유`를 에스컬레이션 판정에 추가했습니다. `머지`는 `나머지` 안에서도 걸리기 때문에 앞 글자가 `나`가 아닐 때만 인정합니다. 실제 프롬프트 1,276건에서 이 오탐이 7건 있었습니다.
- **구현 요청은 실행이나 확인 동사가 섞여 있어도 힌트를 내지 않습니다.** "설치와 동시에 설정되도록 하자", "피드백 확인해주고 아이콘도 만들자" 같은 문장은 `설치`·`확인` 때문에 명령 실행이나 상태 확인으로 분류되었지만 실제로는 코드를 고치는 일입니다. 프롬프트가 들어온 시점에는 도구 호출 기록이 없어 문장으로만 판단해야 하므로, 구현 동사가 보이면 힌트를 접습니다. 오프라인 스캔은 도구 사용 비율로 이미 같은 경우를 걸러 내므로 그대로 둡니다.
- 같은 1,276건에 변경 전후 힌트를 돌린 결과 395건에서 365건으로 줄었고, 사라진 30건 중 26건은 잘못된 대상에 위임을 권하던 힌트였습니다. 새로 생긴 힌트는 없습니다. 오프라인 스캔의 후보와 룰에는 변화가 없습니다.
