- **The prompt-time hint now names only tiers cheaper than the model reading it.** The hint repeated both tiers a rule carries, whatever the session ran on, so a Sonnet session was told to "delegate to model: sonnet when it spans multiple steps" — a delegation to itself, which saves nothing and contradicts the registry's own clause that a session already at the target tier does not delegate. Tiers that cannot pay off are now dropped, and when none is left (a haiku session) the hint stays quiet.
- The session's model is read from its own transcript. The UserPromptSubmit payload names the session but not its model, and the statusline snapshot is a single file shared by every session on the machine, so with two sessions open the last one to tick decides what it says. The transcript comes first, then the gateway model environment, and only then the snapshot. Because this runs inside a prompt hook, the transcript is read backwards within its last 4MB; a session with no assistant turn in that range is reported as unknown rather than re-read from the start.
- An unrecognized model name leaves the hint as it was. `modelRank()` prices an unknown string as Sonnet so that a cost estimate always has an answer, but carrying that guess here would silence every T1 hint behind a gateway whose house alias (`prod-large`) names no Claude family. Tiers are filtered only for a recognized model id or an alias that resolves through `profile-map.json`.

## 한국어

- **프롬프트 시점 힌트가 지금 세션이 쓰는 모델보다 싼 티어만 권합니다.** 힌트는 룰에 적힌 두 티어를 세션과 무관하게 그대로 읽어 주었습니다. 그래서 Sonnet 세션이 "여러 단계가 얽히면 model: sonnet 에 위임하라"는 문장을 받았습니다. 자기 자신에게 넘기라는 뜻이라 절감이 없고, 세션 모델이 목표와 같은 급이면 위임하지 않는다는 레지스트리 자체 조항과도 어긋납니다. 이제 이득이 없는 티어는 힌트에서 빼고, 남는 티어가 없으면(haiku 세션) 아무 말도 하지 않습니다.
- 세션 모델은 그 세션의 트랜스크립트에서 읽습니다. UserPromptSubmit 페이로드는 세션을 알려 주지만 모델은 알려 주지 않고, statusline 이 남기는 스냅샷은 기기 전체가 한 파일을 나눠 쓰므로 세션 두 개가 열려 있으면 마지막으로 갱신한 쪽이 답을 정합니다. 그래서 트랜스크립트를 먼저 보고, 없으면 게이트웨이 환경 변수, 그다음에야 스냅샷을 봅니다. 트랜스크립트는 훅 안에서 읽으므로 끝에서 4MB 안쪽만 거꾸로 훑고, 그 범위에 어시스턴트 턴이 없으면 전체를 다시 읽지 않고 미상으로 둡니다.
- 모델 이름을 알아보지 못하면 예전처럼 동작합니다. `modelRank()` 는 비용 추정에 항상 답을 주려고 모르는 문자열을 Sonnet 으로 매기는데, 그 추측을 그대로 쓰면 `prod-large` 같은 게이트웨이 별칭을 쓰는 환경에서 T1 힌트가 전부 사라집니다. 알아보는 모델 id 이거나 `profile-map.json` 으로 풀리는 별칭일 때만 티어를 거르고, 그 밖에는 거르지 않습니다.
