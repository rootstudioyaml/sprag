- **The prompt-time hint decides an agent's name from the session's project root.** `routeHint` takes a `root` option and names a subagent only when `<root>/.claude/agents/<name>.md` exists, but `sprag brief --hook` — the one real caller — never passed it, so the check fell back to the hook process's working directory. When that directory is not the project root, an installed agent is announced as a bare `model: haiku` and the model is not told what to spawn. The hook payload's `cwd` is now handed through, matching what the PreToolUse hook already did with the same payload; a payload without `cwd` behaves as before. Every unit test pinned `root` itself, which is why nobody saw the caller's omission, so a test that runs the real hook and checks the name appears from the payload alone ships with the fix.
- **Tests no longer hand the shell environment to their child processes.** Running `npm test` from an IntelliJ terminal leaked `TERMINAL_EMULATOR` into children, drew the statusline in narrow mode, and failed five effort and ultracode tests that pin the `🔬` chip — on correct code. This is the same shape as the `COLORTERM` case in v3.50.0, so it is settled in one place: `test/helpers/child-env.js` strips the 39 environment variables this tool reads, and each test sets back only what its case needs. `test/child-env.test.js` reports any name missing from that list and also checks that no test passes the shell environment wholesale. `HOME` must be named by the caller, because otherwise POSIX `homedir()` answers from the passwd entry and the child reads the real user's `~/.claude`.
- **`sprag delegate on` appends bounds and already-read paths to Task/Agent delegation prompts.** Whether a subagent inherits the parent session's SessionStart guidance (Korean style, ratchet rules) is undocumented, and an unbounded subagent commonly searches until its context runs out rather than until it has the answer. A PreToolUse hook intercepts the prompt and adds, per condition: tool-call and output bounds (8 calls / 1,500 tokens for a haiku target, 20 / 8,000 otherwise), the Korean style guidance when the target is Korean or a `.ko.` file, a note when `CLAUDE.md` does not import `ratchet.md`, and recent paths recovered from the transcript tail. It is off by default; `sprag delegate on|off|status` controls it. The path window is the last 4MB of the transcript, because transcript bulk is tool *results* — file contents, command output, images — not the calls, so a byte window is far shallower than it looks: on a real 4.65MB session, 256KiB covered 28 lines, 1.9% of the session, and recovered none of its 8 path-bearing calls. Reading 4MB costs 11.5ms against a 10-second hook limit. Only files are listed, since `Grep` and `Glob` arguments are often directories and handing a subagent a directory to read spends one of its bounded calls on a failure. Paths carrying control characters, Unicode line separators or backticks are left out, because the list is one path per line inside a prompt and a newline in a filename makes what follows read as a separate instruction. `delegate off` removes only entries whose command is our executable, and only that hook entry rather than its matcher group — judging by the flag alone would also delete a user's own `other-tool delegate --hook`, and Claude Code merges same-matcher hooks into one group, so removing the group takes another tool's hook with it. `sprag delegate on` turns the feature on only after the hook registers, so a failed `settings.json` write cannot leave a setting that claims to be on while calling nothing, and `sprag uninstall` turns it off as it removes the hook. `sprag delegate` status adds a line of reason whenever `settings.json` needs attention. The path list holds at most 15, newest first.

## 한국어

- **프롬프트 시점 힌트가 세션의 프로젝트 루트를 보고 에이전트 이름을 정합니다.** `routeHint` 는 `root` 옵션을 받아 `<root>/.claude/agents/<이름>.md` 가 있을 때만 서브에이전트 이름을 적습니다. 그런데 실제 호출부인 `sprag brief --hook` 이 그 값을 넘기지 않아, 판정이 훅 프로세스의 작업 디렉터리로 떨어졌습니다. 그 디렉터리가 프로젝트 루트와 다르면 설치해 둔 에이전트가 이름 없이 `model: haiku` 로만 안내되므로, 모델은 무엇을 띄워야 하는지 알지 못합니다. 이제 훅 페이로드의 `cwd` 를 그대로 넘기며, 같은 페이로드를 이미 읽고 있던 PreToolUse 훅과 처리 방식이 같아졌습니다. `cwd` 가 없는 페이로드에서는 이전과 동일하게 동작합니다. 단위 테스트가 하나같이 `root` 를 고정해 두어 호출부의 누락을 아무도 보지 못했기 때문에, 실제 훅을 띄워 페이로드만으로 이름이 붙는지 확인하는 테스트를 함께 넣었습니다.
- **테스트가 자식 프로세스에 셸 환경을 그대로 넘기지 않습니다.** `npm test` 를 IntelliJ 터미널에서 실행하면 `TERMINAL_EMULATOR` 가 자식까지 따라가 statusline 이 narrow 모드로 그려졌고, `🔬` 칩을 고정해 둔 effort·ultracode 테스트 5건이 정상 코드에서 실패했습니다. v3.50.0 의 `COLORTERM` 사례와 같은 유형이므로 이번에는 공용 헬퍼 `test/helpers/child-env.js` 로 정리했습니다. 이 도구가 읽는 환경 변수 39개를 자식 환경에서 덜어 내고, 각 테스트는 자기 사례에 필요한 값만 다시 지정합니다. 목록이 소스와 어긋나면 `test/child-env.test.js` 가 빠진 이름을 지적하고, 어떤 테스트도 셸 환경을 통째로 넘기지 못하도록 같은 파일이 함께 검사합니다. `HOME` 은 호출하는 쪽이 반드시 지정하게 했습니다. 지정하지 않으면 POSIX `homedir()` 가 passwd 항목으로 답해 자식이 실제 사용자의 `~/.claude` 를 읽었기 때문입니다.
- **`sprag delegate on` 이 Task/Agent 위임 프롬프트에 상한과 이미 읽은 경로를 덧붙입니다.** 서브에이전트가 부모 세션의 SessionStart 지침(한국어 문체, 래칫 규칙)을 물려받는지는 문서화되어 있지 않고, 상한 없이 맡기면 답을 찾을 때까지가 아니라 자기 컨텍스트가 바닥날 때까지 탐색하는 경우가 흔합니다. PreToolUse 훅으로 프롬프트를 가로채, 도구 호출·출력 상한(대상이 haiku 면 8회·1,500 토큰, 그 외는 20회·8,000 토큰)과 한글이거나 `.ko.` 대상일 때의 한국어 문체 지침, `CLAUDE.md` 가 `ratchet.md` 를 import 하지 않았을 때의 안내, 트랜스크립트 꼬리에서 찾은 최근 경로를 조건별로 붙입니다. 기본값은 꺼짐이며 `sprag delegate on\|off\|status` 로 켭니다. 경로를 찾는 창은 트랜스크립트 끝에서 4MB 입니다. 트랜스크립트의 부피는 도구 호출이 아니라 도구 결과(파일 내용, 명령 출력, 이미지)가 차지하므로 바이트로 자른 창은 보기보다 훨씬 얕습니다. 실제 4.65MB 세션에서 256KiB 는 28줄, 세션의 1.9% 만 담아 그 세션이 실행한 경로 호출 8건을 하나도 회수하지 못했습니다. 4MB 읽기는 11.5ms 로 훅 제한 10초에 비해 무게가 없습니다. 목록에는 파일만 올립니다. `Grep`·`Glob` 의 인자는 디렉터리일 때가 많고, 디렉터리를 읽으라고 건네면 서브에이전트가 상한 한 칸을 실패로 씁니다. `delegate off` 는 우리 실행 파일이 명령 자리에 있는 항목만 지웁니다. 플래그만 보고 판정하면 사용자가 직접 등록한 `other-tool delegate --hook` 까지 함께 지워지며, 이 저장소는 v3.46.1 에서 같은 실수를 이미 한 번 겪었습니다. 제어 문자가 든 경로도 올리지 않습니다. 목록은 프롬프트 안에서 한 줄이 한 경로인데, 파일명에 개행이 들어가면 그 뒤가 별도 지시문처럼 읽힐 수 있습니다. `delegate off` 는 matcher 그룹이 아니라 훅 항목 하나만 지웁니다. Claude Code 가 같은 matcher 를 한 그룹으로 합치므로, 그룹째 지우면 같은 그룹에 있던 다른 도구의 훅이 함께 사라집니다. `sprag delegate on` 은 훅 등록이 성공한 뒤에 기능을 켭니다. 먼저 켜면 `settings.json` 을 고칠 수 없을 때 켠 줄 알지만 아무것도 부르지 않는 상태가 남습니다. `sprag uninstall` 은 훅을 지우면서 이 설정도 함께 끕니다. 설정은 취향이 아니라 훅이 등록되어 있다는 주장이므로, 훅이 사라진 뒤에도 남으면 `delegate: on, hook 미등록` 이 됩니다. 나머지 설정은 그대로 둡니다. `sprag delegate` 상태 출력은 `settings.json` 을 손봐야 하는 경우 그 사유를 한 줄 더 보여 줍니다. 경로 목록은 가장 최근 것부터 최대 15개이고, 줄을 끊거나 인용을 닫을 수 있는 문자(제어 문자, 유니코드 줄 구분자, 백틱)가 든 경로는 올리지 않습니다.
