- **One `npm i -g sprag-cli` now sets everything up, Codex included.** Install no longer asks questions; it registers the bundled recommended rules and, when Codex is present, its hooks and `AGENTS.md` harness too.
- **The Codex panel now opens inside the same terminal by default.** On macOS with zsh, install and upgrade set up tmux so no separate Terminal window opens per session.
- **Global presets now live in their own `ratchet-preset.md`.** Upgrades can update or drop preset wording without touching the rules you wrote in `ratchet.md`.

### Install

Install asks nothing and registers the bundled recommended rules for every
project. If Codex is installed (`~/.codex` or `$CODEX_HOME`), the Codex hooks,
the `AGENTS.md` harness and the Codex recommended rules are registered as well,
so `sprag install --agent codex` is no longer a separate step. Codex still
requires you to trust the hooks in `/hooks`. The old step-by-step flow is
available as `sprag install --manual`, and `sprag uninstall` also removes the
Codex entries that install registered on its own.

### Codex Panel

On macOS with zsh, install and upgrade check for tmux, install it with Homebrew
when missing, and add the zsh integration. The panel keeps the separate-window
mode when tmux cannot be installed, the shell is not zsh, or a `codex` alias
already exists. Turning it off with `sprag panel shell remove --agent codex`
survives reinstalls and upgrades, and `CTS_NO_TMUX=1` skips the tmux install.
`sprag upgrade` now runs the new version's `sprag install` itself, so installs
that skip postinstall (pnpm, bun) still finish setup.

### Presets

Presets are written to `~/.claude/ratchet-preset.md` (for Codex,
`$CODEX_HOME/ratchet-preset.md`), which Sprag rewrites from your recorded
answers at every session start. The global harness block gains an
`@~/.claude/ratchet-preset.md` import, added once to existing installs. Presets
that older versions appended to `ratchet.md` are moved only when a line matches
the bundled wording exactly, and the original is kept as
`ratchet.md.bak-preset-migration`. Remove a preset with `sprag seed skip <id>`;
`sprag harness list --global` lists presets separately. Presets registered with
`--project` still go into that project's `ratchet.md`.

### Site and Fixes

The homepage and the GitHub and npm READMEs now present Sprag as a token saver,
led by a 41-second side-by-side video in English and Korean. Its prices come
from public rates, and the delegated side includes the cost of the parent
session re-reading the conversation. `npm version` now also bumps
`softwareVersion` in `site/index.html`, which stayed at 3.53.0 in v3.54.0 and
failed `test/site-md.test.js` on every CI runner. Tests that failed only on
Windows were fixed (8.3 short paths, absolute ESM import paths, path
separators, drive letters in `CODEX_HOME`, `Path` casing, and `ENOTEMPTY` on
temp cleanup).

## 한국어

- **`npm i -g sprag-cli` 한 번으로 Codex까지 설치가 끝납니다.** 설치는 아무것도 묻지 않고 동봉된 추천 룰을 등록하며, Codex가 있으면 Codex 훅과 `AGENTS.md` 하네스도 함께 등록합니다.
- **Codex 패널이 기본으로 같은 터미널 안에 뜹니다.** macOS zsh 환경에서 설치와 업그레이드가 tmux를 준비하므로, 세션마다 별도 Terminal 창이 열리지 않습니다.
- **전역 프리셋은 이제 `ratchet-preset.md`에 따로 둡니다.** 업그레이드에서 프리셋 문구가 바뀌거나 빠져도 사용자가 쓴 `ratchet.md`는 건드리지 않습니다.

### 설치

설치는 아무것도 묻지 않고, 동봉된 추천 룰을 전체 프로젝트에 등록합니다.
Codex가 설치되어 있으면(`~/.codex` 또는 `$CODEX_HOME`) Codex 훅과 `AGENTS.md`
하네스, Codex용 추천 룰까지 함께 등록하므로 `sprag install --agent codex`를
따로 실행할 필요가 없습니다. Codex의 `/hooks`에서 훅을 신뢰하는 절차는 Codex가
요구하므로 남아 있습니다. 단계마다 확인하던 예전 방식은 `sprag install --manual`로
쓸 수 있고, `sprag uninstall`은 설치가 스스로 등록한 Codex 항목도 함께 지웁니다.

### Codex 패널

macOS zsh 환경에서 설치와 업그레이드가 tmux를 확인하고, 없으면 Homebrew로 설치한
뒤 zsh 연동을 추가합니다. tmux를 설치할 수 없거나 셸이 zsh가 아니거나 기존
`codex` 별칭이 있으면 별도 창 방식을 유지합니다. `sprag panel shell remove --agent codex`로
끈 설정은 재설치와 업그레이드에도 유지되고, `CTS_NO_TMUX=1`은 tmux 설치를
건너뜁니다. `sprag upgrade`는 pnpm·bun처럼 postinstall을 건너뛰는 설치에서도 새
버전의 `sprag install`을 직접 실행합니다.

### 프리셋

프리셋은 `~/.claude/ratchet-preset.md`(Codex는 `$CODEX_HOME/ratchet-preset.md`)에
들어가며, sprag가 세션을 시작할 때마다 응답 기록으로 이 파일을 통째로 다시 씁니다.
전역 하네스 블록에 `@~/.claude/ratchet-preset.md` import가 추가되고, 기존 설치의
블록에도 한 번 덧붙습니다. 예전 버전이 `ratchet.md`에 덧붙인 프리셋은 문구가 번들과
정확히 같은 줄만 골라 옮기며, 원본은 `ratchet.md.bak-preset-migration`으로 남깁니다.
등록한 프리셋은 `sprag seed skip <id>`로 뺄 수 있고, `sprag harness list --global`이
따로 보여 줍니다. `--project`로 등록한 프리셋은 지금처럼 그 프로젝트의 `ratchet.md`에
들어갑니다.

### 홈페이지와 수정 사항

홈페이지와 GitHub·npm README가 Sprag를 토큰 절감 도구로 소개하며, 같은 요청을 두
터미널에 넣어 비교하는 41초 영상을 영어와 한국어로 올렸습니다. 금액은 공개 단가로
계산했고, 위임 쪽 비용에는 부모 세션이 대화를 다시 읽는 몫을 포함했습니다.
`npm version`이 `site/index.html`의 `softwareVersion`을 함께 올립니다. v3.54.0에서
이 값이 3.53.0에 머물러 모든 CI 러너에서 `test/site-md.test.js`가 실패했습니다.
Windows에서만 실패하던 테스트도 고쳤습니다. 원인은 8.3 짧은 경로, ESM import에 쓴
절대 경로, 경로 구분자, `CODEX_HOME`에 붙는 드라이브 문자, `Path` 대소문자, 임시
디렉터리 정리 시 `ENOTEMPTY`였습니다.
