- **Cost and routing savings are now priced by the path each call took.** Claude sessions on a gateway use that gateway's `/model/info` prices, and Codex uses OpenAI list prices for direct ChatGPT/OpenAI calls and gateway prices for LiteLLM providers.
- **A delegation to a pricier model is now recorded as a loss.** Savings are signed on both agents and print as `-$0.12`, and Codex rules gain the same rule-health check Claude rules have.
- **Codex session-start guidance is no longer cut in the middle.** Parts are fitted whole within Codex's hook context limit, and whatever does not fit goes to a file the session is told to read first.

### Pricing

A Claude session whose `ANTHROPIC_BASE_URL` points to a gateway is billed by
that gateway, so actual cost, month spend and routing savings now come from its
`/model/info` prices. A model the gateway does not price stays unpriced and is
counted as `+N unpriced`; it is never filled in from the Anthropic list prices.
Codex calls that go straight to OpenAI (ChatGPT login or an API key to
`api.openai.com`) use built-in OpenAI list prices: Standard tier, short-context
rates, checked 2026-10-01, with long-context surcharges not modeled. Before this
release, gateway users were priced at Anthropic list prices, and ChatGPT-login
Codex users saw every routing saving and every "cheaper model" suggestion as
unpriced.

### Delegation

Claude used to clamp a negative saving to zero and drop it from the ledger, so a
rule that lost money never showed in the totals. Both agents now keep the sign.
`sprag delegate rules --agent codex` lists each rule's measured runs, failure
rate and saving, and flags a rule when the 95% lower bound of its failure rate
exceeds 20% over at least five runs. The Codex ledger binds pending routes
oldest first, prunes expired ones and stores amounts rounded to $0.0001.

### Codex

Codex 0.159.2 keeps about 2,450 tokens of one hook's context and cuts the middle
of anything longer, so the 4,500-token session-start context lost most of the
Korean style guide while the preset offer at its end survived. Session start now
fits its parts whole by priority and writes the rest to a per-project file; in a
live run Codex read that file before writing Korean. `codex exec` runs get no
preset offer or route notice, since no one can answer them. Child sessions
spawned with `fork_turns: "all"` are no longer parsed as their parent, repeated
failures are detected across `codex exec` runs of one project, swallowed hook
errors show under `CTS_DEBUG`, and `sprag handoff --agent codex` is recorded in
Codex history.

## 한국어

- **비용과 위임 절감액을 호출이 거친 경로의 단가로 계산합니다.** 게이트웨이(`ANTHROPIC_BASE_URL`)를 거친 Claude 세션은 그 게이트웨이의 `/model/info` 단가로 계산하고, 단가가 없는 모델은 Anthropic 정가로 채우지 않고 `+N unpriced`로 건수만 보여 줍니다. Codex는 ChatGPT·OpenAI 로그인으로 바로 호출하면 내장된 OpenAI 정가를 쓰고, LiteLLM 공급자를 거치면 그 게이트웨이의 단가를 씁니다. 그동안 게이트웨이 사용자도 Anthropic 정가로 계산됐고, ChatGPT 로그인으로 Codex를 쓰는 사용자는 위임 절감액과 route-scan의 "더 싼 모델" 판정이 모두 미상이었습니다. OpenAI 정가는 공식 가격 페이지의 Standard 등급 짧은 컨텍스트 단가이고 2026-10-01에 확인했습니다. 긴 컨텍스트 할증은 반영하지 않습니다.
- **더 비싼 모델로 위임한 건은 손실로 기록합니다.** Claude 쪽은 음수 절감액을 0으로 자르고 원장에서 뺐기 때문에, 손해를 보는 룰이 합계에 드러나지 않았습니다. 이제 Claude와 Codex 모두 부호를 그대로 남기고 `-$0.12`처럼 표시합니다. Codex 룰에도 Claude와 같은 기준의 rule-health를 넣어, `sprag delegate rules --agent codex`가 룰마다 실측 위임 건수와 실패율, 절감액을 보여 주고 실패가 잦은 룰을 알립니다.
- **Codex 세션 시작 지침이 가운데에서 잘리지 않습니다.** Codex 0.159.2는 훅 하나의 컨텍스트를 약 2,450토큰까지만 보존하고 가운데를 잘라 내므로, 4,500토큰이던 주입문에서 한국어 문체 지침 대부분이 사라지고 끝의 추천 룰 제안만 남았습니다. 이제 우선순위대로 잘리지 않은 항목만 넣고, 들어가지 못한 지침은 파일에 써서 첫머리에서 읽으라고 안내합니다. 실측에서 Codex가 그 파일을 먼저 읽고 한국어 파일을 작성했습니다. `codex exec` 실행에는 답할 사람이 없으므로 추천 룰 제안과 route 안내를 넣지 않습니다.
- `fork_turns: "all"`로 생성된 Codex 자식 세션을 부모 세션으로 읽던 파서 버그를 고쳤습니다. 자식 rollout에는 부모의 `session_meta`와 대화가 복사되어 들어가는데, 파서가 뒤의 복사본으로 식별 정보를 덮어써서 자식이 부모 id로, 서브에이전트가 아닌 세션으로 집계됐습니다. 복사된 부모 턴의 모델이 섞여 위임 원장에서 그 실행이 미상으로 남는 문제도 함께 사라졌습니다.
- Codex 위임 원장이 대기 중인 위임 기록을 가장 오래된 것부터 연결하고, 만료된 기록을 정리하며, 금액을 0.0001달러 단위로 반올림해 저장합니다. Codex ratchet 후보 감지는 같은 프로젝트에서 30분 안에 생긴 다른 rollout도 함께 읽으므로, `codex exec`를 반복할 때 되풀이된 실패도 잡습니다.
- Codex 훅과 명령 경로에서 삼키던 오류를 `CTS_DEBUG`로 볼 수 있습니다. `sprag handoff --agent codex`는 작성 기록을 Codex history에 남기고, history 도움말은 컨텍스트와 사용 한도 경고만 기록한다고 밝힙니다.
