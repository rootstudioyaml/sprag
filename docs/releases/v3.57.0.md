- **Reported cost is closer to what was billed.** Subagent spend now counts toward actual cost and month spend, a session copied under two project folders counts once, and a session that switched model is priced model by model.
- **Installing no longer damages your settings.** An unreadable `settings.json` is left alone instead of overwritten, only Sprag's own hooks are removed, and npm's `postinstall` sets Claude Code up for a global install only.
- **Delegation hints and context warnings match the session they describe.** Reviews, security checks and root-cause asks no longer get a cheap-model hint, and the context warning is measured against the window Claude Code reports.

### Cost

Requests made by a session's subagents were never read, so actual cost and the
month chip left them out: about $175 over 30 days on the machine this was
measured on. Each run is now priced at its own model and added to its session.
A project folder that was renamed or copied leaves the same transcript in two
places, and every total counted it twice; transcripts are now deduplicated by
name. Month spend drops what a session spent before the 1st, and a session that
used `/model` midway is priced per model instead of whole at the model that
answered most often. Zero-token `<synthetic>` stubs no longer count as API
calls, and a transcript holding nothing else is no longer a session (2,163 of
them in 30 days on the measured machine). The single-line and multi-line
statuslines showed two different "Routing saved" amounts, and two global rules
of one category both claimed the same delegated runs; both read one ledger now.
The session cache format changed, so the first run after upgrading re-reads
every transcript once.

The spike baseline now takes sessions of three requests or more. When most
sessions are one-shot scripted calls, the baseline sat near 50k tokens and an
ordinary session read as "252× p95". The daily trend is keyed by the local day,
like the month total beside it.

### Install and settings

`--install-hook` treated a `settings.json` it could not parse as empty and wrote
over it. Settings and state files are now written through a temp file and a
rename, an unusable file is left untouched, and a state file that fails to
parse is copied aside before it is replaced. A hook counted as Sprag's when its
command merely contained Sprag's text, and removing it dropped the whole matcher
group; ownership is now decided by the executable and its leading arguments.

`postinstall` ran the setup for every install, including a project dependency,
the `npx` cache and CI. Those do not put `sprag` on PATH, so the hooks they
registered called a command that was not there. npm now runs the setup for a
global install only and never under CI. `SPRAG_POSTINSTALL=1` forces it,
`SPRAG_POSTINSTALL=0` skips it, and `sprag install` does the same thing by hand.

A project's `apiKeyHelper` runs only in a folder Claude Code has recorded as
trusted, so running the CLI inside a downloaded repository no longer runs that
repository's command. The doc2md hook no longer answers the permission question
when it only has a note to add. The Python libraries the document converter
installs carry an upper version bound, and the `.fig` parser is installed with
`--ignore-scripts`.

### Delegation and briefing

Requests phrased as a check ("is there a security hole", "find the cause of this
bug", "review the code") got a haiku delegation hint. They stay on the session
model now, and English keywords match as whole words, so `pipeline` is no longer
a `pip` command. Measured on 10,958 local prompts: of the 300 short ones that
had a hint, 18 lose it and none gains one.

The context warning guessed the window from the model id, which names 1M only
through a `[1m]` suffix. A model that is 1M without one read as 200k, and the
80% warning fired at 160k. The statusline now records the window size Claude
Code reports, and the briefing reads it back for the same session.

The delegation guard told the subagent a fixed cap while the routing hint stated
the rule's calibrated one; the guard now repeats the cap of the rule the turn
matched. Candidate numbers (`R2`) stay put across rescans, so a rescan between
the offer and `promote R2` cannot register another pattern. The global
`ratchet-model.md` is written the same from every directory, which keeps it out
of the way of the prompt cache, and a rule that stopped firing no longer keeps
its last figures and its review flag.

### Reports, Codex and the Korean check

The table report honours `--no-color` and writes no escape codes to a pipe or a
file. Its English output carried a Korean label, a loss printed as `$-3`, five
documents said the default period is one day while the code uses 30, and
`--help` left out ten subcommands. `claude-opus-4-20250514` displayed as
"Opus 4.20250514", and `claude-3-5-haiku` was priced at the 4.5 rate. A standing
cap warning was logged again whenever the warning chip changed, and the LiteLLM
budget gauge kept the previous gateway's amounts after the base URL changed.

Codex: a rate limit warning is no longer repeated on every prompt, rule health
counts only the runs of that rule's project since the rule was created, and a
failing rule shows in the panel and the briefing. A routing hint no child
claimed is closed by the next prompt, so an unrelated child spawned later is not
booked as a saving, and delegation savings are priced at the next prompt instead
of the next route scan. `uninit` removes the block from `AGENTS.md` after an
override file took over, and repeated install and uninstall leave no extra blank
lines. `delegate off` and `delegate status` work with a damaged rule file.

The Korean write check catches past-tense double passives, leaves digit
positions and "located at" phrases alone, and no longer takes seconds on a long
run of Hangul.

## 한국어

- **비용 집계가 실제 청구에 더 가까워졌습니다.** 서브에이전트가 쓴 금액이 Actual cost와 월 지출에 들어가고, 이름이 바뀐 프로젝트 폴더에 남은 같은 세션은 한 번만 셉니다. 월 지출은 1일 0시를 넘긴 세션에서 전월분을 빼고, 세션 도중 모델을 바꾼 경우에는 모델마다 그 모델의 단가로 계산합니다. 토큰이 0인 `<synthetic>` 항목은 API 호출 수와 세션 수에서 빠집니다. 측정한 머신에서는 서브에이전트 지출이 30일에 약 175달러였고, 요청이 `<synthetic>`뿐인 세션이 2,163개였습니다. 한 줄 상태줄과 여러 줄 상태줄이 서로 다른 "Routing saved" 금액을 보여 주던 문제와, 같은 위임이 전역 룰 두 개에 중복으로 잡히던 문제도 고쳤습니다. 세션 캐시 형식이 바뀌므로 업그레이드 직후 한 번은 전체를 다시 읽습니다.
- **설치가 사용자의 설정 파일을 훼손하지 않습니다.** 읽지 못한 `settings.json`을 빈 파일로 보고 덮어쓰던 경로를 막았고, 설정과 상태 파일은 임시 파일에 쓴 뒤 이름을 바꾸는 방식으로 저장합니다. 훅은 실행 파일과 앞쪽 인자로 sprag의 것인지 판정하므로, 문자열이 겹친다는 이유로 다른 도구의 훅이 지워지지 않습니다. npm의 `postinstall`은 전역 설치일 때만 설정을 실행하고 CI에서는 건너뜁니다. 프로젝트 의존성이나 `npx` 캐시로 설치하면 `sprag`가 PATH에 없는데도 훅이 등록되어, 없는 명령을 부르는 훅이 남았기 때문입니다. `SPRAG_POSTINSTALL=1` 또는 `0`으로 강제할 수 있고, `sprag install`을 직접 실행해도 같습니다. 프로젝트 설정의 `apiKeyHelper`는 Claude Code가 신뢰한다고 기록한 폴더에서만 실행하며, doc2md 훅은 안내만 할 때 읽기 권한을 대신 승인하지 않습니다. 문서 변환기가 설치하는 Python 라이브러리에 버전 상한을 두었고, `.fig` 파서는 설치 스크립트 없이 설치합니다.
- **위임 안내와 컨텍스트 경고가 실제 상황에 맞게 나옵니다.** 리뷰, 보안 점검, 버그 원인 확인처럼 판단이 필요한 요청에는 하위 모델 위임 안내를 붙이지 않고, 영어 키워드는 단어 단위로만 일치시킵니다(`pipeline`이 `pip` 명령으로 분류되지 않습니다). 컨텍스트 경고는 Claude Code가 상태줄에 알려 준 창 크기를 기준으로 삼습니다. 모델 id에 `[1m]`이 없는 1M 모델을 200k로 판정해 16만 토큰에서 "80%" 경고를 내던 문제입니다. 위임 가드가 서브에이전트에 알리는 상한은 그 턴에 해당한 룰의 상한과 같아졌고, 후보 번호(`R2`)는 다시 스캔해도 바뀌지 않습니다. 전역 `ratchet-model.md`는 어느 디렉터리에서 스캔했는지와 무관하게 같은 내용으로 쓰이므로 프롬프트 캐시가 유지됩니다.
- 스파이크 기준선에서 요청이 3건 미만인 세션을 뺐습니다. 스크립트가 띄운 1회성 세션이 대부분이면 기준선이 5만 토큰 근처로 내려가 평범한 세션이 "252× p95"로 표시됐습니다. 일별 추이의 날짜는 월 지출과 같은 로컬 시간 기준입니다.
- 표 리포트에 `--no-color`가 적용되고, 파이프나 파일로 내보낼 때는 색상 코드를 넣지 않습니다. 영어 리포트에 섞여 있던 한국어 문구를 고쳤고, 손실은 `-$3`으로 표시합니다. 기본 기간을 1일이라고 적었던 문서 다섯 곳을 코드와 같은 30일로 고쳤으며, `--help`에 빠져 있던 하위 명령 10개를 넣었습니다. `claude-opus-4-20250514` 같은 id가 "Opus 4.20250514"로 표시되던 문제와 `claude-3-5-haiku`가 4.5 단가로 계산되던 문제도 고쳤습니다.
- 한도 경고가 떠 있는 동안 칩이 바뀌면 같은 경고가 history에 다시 기록되던 문제를 고쳤습니다. LiteLLM 예산 게이지는 게이트웨이 주소가 바뀌면 이전 게이트웨이의 금액을 버립니다.
- Codex: 한도 경고가 프롬프트마다 반복되지 않습니다. 룰 건강도는 그 룰의 프로젝트와 생성 시점 이후의 실행만 세고, 실패가 잦은 룰은 패널과 브리핑에 표시됩니다. 어떤 자식도 가져가지 않은 위임 안내는 다음 프롬프트에서 닫히므로 나중에 뜬 무관한 자식이 절감으로 잡히지 않고, 위임 절감액은 다음 route-scan을 기다리지 않고 다음 프롬프트에서 계산됩니다. `AGENTS.override.md`가 생긴 뒤에도 `uninit`이 `AGENTS.md`의 블록을 지우고, 설치와 제거를 반복해도 빈 줄이 늘지 않습니다. 룰 파일이 깨져도 `delegate off`와 `delegate status`가 동작합니다.
- 한국어 쓰기 검사가 `보여졌다`, `쓰여졌다`, `되어졌다` 같은 과거형 이중 피동을 잡습니다. `한 자리 밀리초`처럼 자릿수를 세는 표현과 `서버에 있어서`처럼 위치를 말하는 표현은 지적하지 않습니다. 긴 한글 문자열에서 검사가 수십 초 걸리던 규칙도 고쳤습니다.
