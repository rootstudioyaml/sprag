
- **The install now asks how to show the statusline when you already have one.** With a terminal attached, both the default install and `--manual` offer three choices: show both (the default), replace yours, or keep yours. Showing both prints your command's output first and sprag's lines below it, saves your original entry as `statuslineBase` in the config, and `sprag uninstall` puts it back. If your command fails or takes longer than 1.5 seconds, only sprag's lines are shown, and a wrapper that calls `sprag --statusline` itself does not start your command again. Postinstall, CI and piped installs cannot ask, so they keep your statusline as before. Until now only `--manual` asked, so anyone who already had a statusline never saw sprag's after a default install.
- **The README and the homepage now lead with Claude Code.** Right below the install command, the README shows what changes after installing in three steps with a statusline sample, and the Codex section moved below the measured results. The homepage selects Claude Code first in the demo and install tabs, and its second button now reads "How it works". The hero's statusline capture was a wide image shrunk into a small box until the text could not be read, so it was re-captured from the same real output with wrapping (`node scripts/docs-statusline.mjs --wrap 1200`).
- **The npm description says what you get, and the keyword list is trimmed from 28 to 16 terms that people actually search for.**
