
- **New models are priced at their list rates.** The price table stopped at 2026-04, so new models were priced at older tiers: Opus 5.5 at Opus 5 rates ($5/$25), Sonnet 5 and 5.5 at $3/$15, Haiku 5.5 at Haiku 4.5 rates (ten times its price), and Fable 5.1 cache reads at $1. They now follow the 2026-10-09 pricing page: Opus 5.5 $4/$20, Sonnet 5 and 5.5 $2/$10, Haiku 5.5 $0.10/$0.50, and Fable 5.1 cache reads $0.25. The planned rise of Sonnet 5 to $3/$15 was cancelled, so $2/$10 is its standard price. Reported spend goes down and savings on runs delegated to Sonnet go up; on the measuring machine this month's spend went from $754 to $421 and routing savings from $143.22 to $188.27. The first run after upgrading re-reads the session cache once.
- **Haiku 5.5 long prompts are priced per request.** Haiku 5.5 charges more ($0.50/$2.50) for a request whose prompt exceeds 100,000 tokens, judged one request at a time. Session totals cannot tell those apart, so such requests are now collected separately and only their share is billed at the higher rate.
- **Rules no longer tell the model to pass a model argument to an installed agent.** A rule read `haiku-runner(model: haiku)`, so the model passed `model: haiku`; the Agent tool's argument overrides the agent's definition, and Claude Code resolves the bare `haiku` alias to Haiku 4.5. An agent file pinned to `model: claude-haiku-5-5` was sent back to 4.5 by following the rule. The phrase now says to leave the argument out. To delegate to Haiku 5.5, set `model: claude-haiku-5-5` in your haiku agent files under `~/.claude/agents/`.
- The README and homepage ledger figures are refreshed to 2026-10-09, and the hero statusline capture no longer carries the Input spike warning that depends on that day's usage.

## 한국어

- **새 모델을 공식 단가로 계산합니다.** 가격표가 2026-04에 멈춰 있어서 새 모델이 옛 등급의 단가로 계산되고 있었습니다. Opus 5.5는 Opus 5 단가($5/$25)로, Sonnet 5와 5.5는 $3/$15로, Haiku 5.5는 Haiku 4.5 단가로, Fable 5.1의 캐시 읽기는 $1로 잡혔습니다. Haiku 5.5는 실제보다 10배 비싸게 계산된 셈입니다. 이제 2026-10-09 공식 가격표대로 Opus 5.5 $4/$20, Sonnet 5와 5.5 $2/$10, Haiku 5.5 $0.10/$0.50, Fable 5.1 캐시 읽기 $0.25로 계산합니다. Sonnet 5를 $3/$15로 올리려던 계획은 취소됐으므로 $2/$10이 정가입니다. 그래서 지출 금액은 내려가고, Sonnet으로 위임한 건의 절감액은 올라갑니다. 측정한 머신에서는 이번 달 지출이 $754에서 $421로, 위임 절감 누적이 $143.22에서 $188.27로 바뀌었습니다. 업그레이드 뒤 첫 실행에서 세션 캐시를 한 번 다시 읽습니다.
- **Haiku 5.5의 긴 프롬프트 단가를 요청마다 따로 적용합니다.** Haiku 5.5는 프롬프트가 10만 토큰을 넘는 요청에 더 높은 단가($0.50/$2.50)를 매기고, 요청마다 따로 판정합니다. 세션 합계로는 이를 가릴 수 없으므로, 10만 토큰을 넘는 요청만 따로 모아 그 몫에만 높은 단가를 적용합니다.
- **설치된 에이전트를 가리키는 룰이 model 인자를 넘기지 않게 합니다.** 룰이 `haiku-runner(model: haiku)`라고 적어서 모델이 `model: haiku`를 넘겼는데, Agent 도구의 model 인자는 에이전트 정의를 덮어쓰고 Claude Code는 `haiku` 별칭을 Haiku 4.5로 해석합니다. 에이전트 파일을 `model: claude-haiku-5-5`로 고정해도 룰을 따르면 4.5로 돌아갔습니다. 이제 `haiku-runner(model 인자 생략)`이라고 적습니다. Haiku 5.5로 위임하려면 `~/.claude/agents/` 의 haiku 에이전트 파일에 `model: claude-haiku-5-5`를 적으십시오.
