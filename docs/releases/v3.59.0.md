
- **The saved counters can be reset like a stopwatch.** `sprag saved reset` starts the routing and document-conversion savings over from now; add `routing` or `doc2md` to reset just one. Nothing is deleted: the reset time is stored in `saved-reset.json`, the statusline and `route-scan savings` add up only the records after it, and `sprag saved undo` brings the previous counters back. `sprag saved` shows each counter with its current amount and last reset time, and `--agent codex` covers the Codex routing and document counters.

## 한국어

- **절감 카운터를 스톱워치처럼 초기화할 수 있습니다.** `sprag saved reset` 은 라우팅 절감과 문서 변환 절감을 지금부터 다시 셉니다. `routing` 이나 `doc2md` 를 붙이면 하나만 초기화합니다. 기록 자체는 지우지 않고 초기화 시각만 `saved-reset.json` 에 남기므로, 상태줄과 `route-scan savings` 는 그 시각 이후의 기록만 합산하고 `sprag saved undo` 로 이전 카운터를 되돌릴 수 있습니다. `sprag saved` 는 카운터마다 현재 금액과 마지막 초기화 시각을 보여 주며, `--agent codex` 를 붙이면 Codex의 라우팅·문서 카운터를 다룹니다.
