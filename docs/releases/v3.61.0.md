- **Codex now follows the delegation rules you approved in Claude.** Codex reads the shared `model-rules.json` registry in place, without copying it, and uses each rule's category, T1/T2 tier, scope and caps as its delegation policy. Claude model names are never taken as Codex models, so each tier runs only after you name its target with `sprag delegate shared map T1 --from <parent model> --model <target model> --agent codex`. Roles, usage and savings are still counted per agent.
- **A Codex-only user can approve the bundled presets.** `sprag seed --agent codex` lists the presets without any Claude settings or transcripts, and an approval records the scope (global or project) and the project you chose.
- **Codex subagents are bound to the tier they were mapped to.** The prompt hint offers each mapped tier as a route, the SubagentStart hook binds the child to its tier by model, and the next prompt closes the tier that was not chosen. When two tiers share a model, the child's route marker decides, and a closed route counts only children that started before it closed. Where the PreToolUse hook runs, a spawn that matches a shared policy but names no model is denied with the mapped choices instead of a guessed tier or default target.
- Project rules apply only when they match the root either agent assigns to the working directory (the CLAUDE.md or AGENTS.md boundary, by real path), and the nearest root wins. Claude's prompt routing now applies the same scope filter.
- `sprag delegate shared status --agent codex` checks the mappings against the configured parent model and shows the context gate, which `sprag delegate shared min-context <tokens|default> --agent codex` changes.
- The repository gains an AGENTS.md for Codex carrying the same project instructions as CLAUDE.md, and a test keeps the two bodies identical.

## 한국어

- **Claude에서 승인한 위임 룰을 Codex도 따릅니다.** Codex가 공통 레지스트리 `model-rules.json` 을 복사하지 않고 그대로 읽어, 유형과 T1·T2 티어, 적용 범위, 상한을 위임 정책으로 씁니다. Claude 모델 이름을 Codex 모델로 짐작하지 않으므로, 티어마다 `sprag delegate shared map T1 --from <부모 모델> --model <대상 모델> --agent codex` 로 대상 모델을 직접 지정해야 실행됩니다. 역할과 사용량, 절감액은 에이전트별로 따로 집계합니다.
- **Codex만 쓰는 사용자도 추천 룰을 승인할 수 있습니다.** `sprag seed --agent codex` 는 Claude 설정 파일이나 대화 기록이 없어도 동봉된 추천 룰을 보여 주고, 승인할 때 고른 범위(전역·프로젝트)와 프로젝트를 그대로 기록합니다.
- **Codex 서브에이전트가 매핑된 티어로 묶입니다.** 프롬프트 안내가 매핑된 티어를 고를 수 있는 경로로 제시하고, SubagentStart 훅이 실행된 자식 에이전트를 모델로 판별해 해당 티어에 연결하며, 다음 프롬프트에서 고르지 않은 티어를 닫습니다. 두 티어가 같은 모델을 쓰면 자식의 경로 표지로 구분하고, 닫힌 경로는 닫히기 전에 시작한 자식만 집계합니다. PreToolUse 훅이 도는 환경에서는 공유 정책에 해당하는 생성 요청이 모델 없이 들어오면, 티어나 기본 대상을 추측하지 않고 매핑된 선택지를 알려 주며 거부합니다.
- 프로젝트 룰은 두 에이전트가 작업 디렉터리에 배정하는 루트(CLAUDE.md 또는 AGENTS.md가 있는 경계, 실제 경로 기준)와 맞을 때만 적용하고, 가장 가까운 루트가 우선합니다. Claude의 프롬프트 라우팅에도 같은 범위 필터를 적용했습니다.
- `sprag delegate shared status --agent codex` 가 매핑을 설정된 부모 모델과 대조하고 컨텍스트 게이트를 보여 줍니다. 게이트 값은 `sprag delegate shared min-context <토큰 수|default> --agent codex` 로 바꿉니다.
- 저장소에 Codex용 AGENTS.md를 추가했습니다. 내용은 CLAUDE.md의 프로젝트 지침과 같고, 두 본문이 어긋나지 않도록 테스트가 지킵니다.
