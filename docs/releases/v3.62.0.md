- **Codex now picks the delegation model for each tier on its own.** Until now, approved shared policies did nothing in Codex until you mapped T1 and T2 to models by hand. Just as Claude Code resolves `haiku` and `sonnet` to real models, an unmapped tier now resolves automatically: among models that are priced on the parent's provider (gateway `/model/info` prices, or OpenAI list prices for direct calls), cost less than the parent, and have already run in your Codex sessions, the cheapest becomes T2 and the next one up becomes T1.
- **An explicit mapping still wins, and automatic resolution can be turned off.** Resolution runs only while `sprag delegate on --agent codex` is set. With a single candidate only T2 is mapped, and with none both tiers stay on the main agent. Nothing is stored, so changes in prices or run history are followed as they happen; `sprag delegate shared auto off --agent codex` disables it.
- **You can see which models were chosen, and why.** `sprag delegate shared status --agent codex` and the install output show the resolved models, or the reason none resolved, and prompt routes record `mapping: auto`.

## 한국어

- **Codex가 난도별 위임 모델을 자동으로 정합니다.** 지금까지는 승인한 공유 정책이 있어도 T1·T2를 모델에 직접 매핑하기 전에는 Codex가 위임하지 않았습니다. 이제 Claude Code가 `haiku` 와 `sonnet` 을 실제 모델로 풀듯이, 매핑하지 않은 난도를 자동으로 정합니다. 부모 모델의 공급자에서 가격이 매겨져 있고(게이트웨이 `/model/info` 가격, OpenAI 직접 호출이면 공개 가격) 부모보다 싸며 이 사용자의 Codex 세션에서 이미 실행된 모델 가운데, 가장 싼 모델이 T2가 되고 그다음 모델이 T1이 됩니다.
- **명시한 매핑이 자동 결정보다 우선하고, 자동 결정은 끌 수 있습니다.** 자동 결정은 `sprag delegate on --agent codex` 상태에서만 동작합니다. 후보가 하나뿐이면 T2만 정하고, 하나도 없으면 두 난도 모두 메인 모델이 처리합니다. 결정 결과를 저장하지 않으므로 가격이나 실행 이력이 바뀌면 그대로 따라가며, `sprag delegate shared auto off --agent codex` 로 끕니다.
- **정해진 모델과 그 이유를 바로 확인할 수 있습니다.** `sprag delegate shared status --agent codex` 와 설치 출력에 자동으로 정해진 모델이 나오고, 정해지지 않았으면 그 이유가 나옵니다. 프롬프트 경로 기록에는 `mapping: auto` 가 남습니다.
