- **On Claude Code 2.1.287 and later, document conversion and delegation cost tracking run inside Claude Code itself.** The new plugin mod `sprag-doc2md` swaps a document Read or @-mention for the converted Markdown in the same call, which saves one tool call per document compared with the settings hook refusing the Read and naming the cache file. `sprag-delegation-meter` records what each subagent actually spent from the API usage of every turn, while the transcript-based ledger keeps running beside it. The installer loads both mods through `CLAUDE_CODE_PLUGIN_DIRS` in `~/.claude/settings.json`, so `npm i -g` is still the whole setup. Nothing is written when you already set that variable in your shell or enabled the same mod through `/plugin`.
- **In Codex, the Korean style guide applies right after install.** Until now the guide went in through the SessionStart hook, but Codex keeps only about 2,000 tokens per hook, so the full guide never fit, spilled to a file, and the model often did not read that file. The full guide now lives in a managed block of the global Codex `AGENTS.md`, which Codex reads in full every session. Install, `sprag korean on|off` and every session start keep the block in sync, and `sprag uninstall --agent codex` removes it.
- **Codex delegation is now on by default.** A user who never changed the setting was treated as having delegation off, so nothing was delegated. It is now off only after `sprag delegate off --agent codex`; run that command if you do not want delegation.
- **A new user with no run history still gets delegation models per tier.** On the built-in OpenAI provider, the models Codex lists for your account (`models_cache.json`) are also candidates, so T1 and T2 resolve even before your first Codex session. When the parent model is already the cheapest one available, the status output gives that as the reason.

## 한국어

- **Claude Code 2.1.287 이상에서는 문서 변환과 위임 비용 기록이 Claude Code 안에서 직접 동작합니다.** 새 플러그인 mod `sprag-doc2md` 는 문서를 Read 하거나 @-멘션할 때 같은 호출 안에서 변환된 Markdown으로 바꿔 줍니다. 그래서 설정 훅이 Read를 거부하고 캐시 파일을 알려 주던 때보다 문서 하나에 도구 호출이 한 번 줄어듭니다. `sprag-delegation-meter` 는 서브에이전트가 실제로 쓴 토큰을 매 턴의 API 사용량에서 기록하며, 기존 대화 기록 기반 장부도 그대로 함께 돌아갑니다. 설치 프로그램이 `~/.claude/settings.json` 의 `CLAUDE_CODE_PLUGIN_DIRS` 로 두 mod를 불러오므로 `npm i -g` 만으로 설정이 끝납니다. 셸에서 이 변수를 이미 지정했거나 `/plugin` 으로 같은 mod를 켜 두었다면 아무것도 쓰지 않습니다.
- **Codex에서 한국어 지침이 설치 직후부터 적용됩니다.** 지금까지는 지침을 SessionStart 훅으로 넣었는데, Codex가 훅 하나에 허용하는 약 2,000토큰 예산에 지침 전문이 들어가지 않아 파일로 밀려났고 모델이 그 파일을 읽지 않는 경우가 많았습니다. 이제 Codex가 세션마다 전부 읽는 전역 `AGENTS.md` 의 관리 블록에 지침 전문을 둡니다. 설치와 `sprag korean on|off`, 세션 시작 때마다 블록을 맞추고, `sprag uninstall --agent codex` 가 블록을 지웁니다.
- **Codex 위임이 기본으로 켜집니다.** 설정을 한 번도 바꾸지 않은 사용자는 지금까지 위임이 꺼진 것으로 처리되어 아무것도 위임되지 않았습니다. 이제 `sprag delegate off --agent codex` 를 실행한 경우에만 꺼지므로, 위임을 원하지 않으면 이 명령으로 끄십시오.
- **실행 기록이 없는 새 사용자도 난도별 위임 모델이 자동으로 정해집니다.** OpenAI 기본 공급자를 쓰면 Codex가 이 계정에 보여 주는 모델 목록(`models_cache.json`)도 후보에 넣으므로, Codex 세션을 한 번도 돌리지 않았어도 T1·T2가 정해집니다. 부모 모델이 이미 가장 싼 모델이면 상태 출력이 그 사실을 이유로 알려 줍니다.
