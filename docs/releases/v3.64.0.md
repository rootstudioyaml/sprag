- **The two mods that did nothing in v3.63.0 now work.** npm 11 does not expand `mod/*/hooks/`, a pattern that ends in a directory, so the v3.63.0 package carried each mod's `plugin.json` and none of its hook files. `sprag-doc2md` and `sprag-delegation-meter` loaded but had no hooks and did nothing, while the settings hooks kept working as before. This package includes `hooks.json` and the hook modules, and the release check now confirms those files for every mod in the actual tarball.
- **Codex now checks that a Korean question gets a Korean answer.** A Stop hook, the sixth Codex hook, compares the current Korean prompt with the final answer and asks for a Korean reply when the answer is not Korean. It skips pasted conversation history, Stop continuations and explicit requests for English, and `sprag korean reply off` turns it off.
- **Codex delegation can be checked instead of assumed.** `sprag delegate doctor --agent codex` reads the local Codex version, feature flags and bundled model catalog, and counts delegation offers as completed, bound, pending or unclaimed. It also points out that an enabled setting does not prove the agent tools exist. To hand off implementation once the design is fixed, `sprag delegate implementation --agent codex` resolves T1 for the current parent model, and the ledger credits savings only to a child session that matches that route.
- **Codex shows what document conversion saved.** The ledger (v2) estimates the difference between Office XML and the converted Markdown at bytes/4 and prices it at the recorded Codex input rate. `sprag doc2md savings --agent codex` and `sprag saved` report it; PDF, Figma, clipped output and unpriced models stay unknown.
- **Codex gets update notices too.** The Codex panel shows the update chip, and SessionStart asks before upgrading. Shared policy outcomes in Codex are judged per provider and parent/child model pair and shown in rule listings, the panel and the brief, kept apart from Claude's statistics. `sprag uninstall --agent codex` now also removes the Codex panel shell wrapper.

## 한국어

- **v3.63.0에서 아무 일도 하지 않던 두 mod가 이제 실제로 동작합니다.** npm 11은 디렉터리로 끝나는 `mod/*/hooks/` 패턴을 펼치지 않아서, v3.63.0 패키지에는 mod마다 `plugin.json` 만 들어가고 훅 파일이 빠졌습니다. 그래서 `sprag-doc2md` 와 `sprag-delegation-meter` 가 로드는 됐지만 훅이 없어 아무것도 하지 않았고, 설정 훅만 예전처럼 돌았습니다. 이번 패키지에는 `hooks.json` 과 훅 모듈이 함께 들어가며, 릴리스 검사가 실제 tarball에서 mod마다 이 파일들이 있는지 확인합니다.
- **Codex도 한국어로 물으면 한국어로 답하는지 확인합니다.** 여섯 번째 Codex 훅인 Stop 훅이 현재 한국어 프롬프트와 최종 답변을 비교해, 답이 한국어가 아니면 한국어로 다시 답하게 합니다. 붙여 넣은 대화 기록, Stop 후속 턴, 영어로 답해 달라는 명시적 요청은 건너뛰며 `sprag korean reply off` 로 끌 수 있습니다.
- **Codex 위임을 추정하지 않고 점검할 수 있습니다.** `sprag delegate doctor --agent codex` 가 로컬 Codex 버전과 기능 플래그, 내장 모델 목록을 읽고, 위임 제안이 완료·연결·대기·미수령 중 어디에 있는지 셉니다. 설정이 켜져 있어도 에이전트 도구가 실제로 있다는 뜻은 아니라는 점도 함께 알려 줍니다. 설계가 정해진 뒤 구현을 넘길 때는 `sprag delegate implementation --agent codex` 가 현재 부모 모델에 맞는 T1을 정하고, 장부는 그 경로와 맞는 자식 세션에만 절감을 기록합니다.
- **Codex에서 문서 변환으로 아낀 양을 볼 수 있습니다.** 장부(v2)가 Office XML과 변환된 Markdown의 차이를 바이트/4로 추정하고, 기록된 Codex 입력 단가로 금액을 매깁니다. `sprag doc2md savings --agent codex` 와 `sprag saved` 가 이 값을 보여 주며, PDF·Figma·잘린 출력·단가가 없는 모델은 알 수 없음으로 둡니다.
- **Codex에도 업데이트 알림이 나옵니다.** Codex 패널에 업데이트 칩이 뜨고, SessionStart가 업그레이드 전에 먼저 묻습니다. 공유 정책의 성과는 Codex에서 공급자와 부모·자식 모델 쌍별로 따로 판정해 룰 목록과 패널, 브리프에 보여 주며 Claude 통계에는 섞지 않습니다. `sprag uninstall --agent codex` 는 이제 Codex 패널 셸 래퍼도 지웁니다.
