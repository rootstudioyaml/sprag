- **The routing headline now shows what delegation cost next to what it saved.** Until now the first line showed only the amount delegation saved, never what the delegated runs themselves cost, so the saving had nothing to be read against. `route-scan` now records each run's cost on the model that actually ran it beside its saving, and the first line reads `Routing saved $15.1 · spent $9.78 since 10/9`. Runs recorded before costs were kept get their cost filled in by the next scan that still covers them. Runs that still have none are counted as `+N unpriced` rather than read as free, and the tag stays hidden until some run carries a cost.
- **The session subagent chip shows what those runs spent.** It reads `Subagents this session 2 (haiku 2) spent $0.02`, pricing each run of this session at its own model's rate. Costs follow the same path as the session cost, so a gateway session uses the gateway's price table. Runs the price table does not know are counted as `+N unpriced`, and the chip shows `n/a` when none can be priced.

- **라우팅 절감액 옆에 그 위임에 든 비용이 함께 나옵니다.** 지금까지 첫째 줄은 위임으로 아낀 금액만 보여 주고 위임 실행 자체에 든 비용은 보여 주지 않아서, 절감액을 무엇과 견주어 읽어야 할지 알 수 없었습니다. 이제 `route-scan` 이 실행마다 실제로 실행된 모델에서 든 비용을 절감액 옆에 기록하고, 첫째 줄이 `Routing saved $15.1 · spent $9.78 since 10/9` 처럼 표시합니다. 비용 기록이 생기기 전에 남은 실행은 그 실행을 아직 포함하는 다음 스캔이 비용을 채웁니다. 그래도 비용이 없는 실행은 0으로 치지 않고 `+N unpriced` 로 개수를 붙이며, 비용이 기록된 실행이 하나도 없으면 이 표시가 나오지 않습니다.
- **이번 세션의 서브에이전트 칩에도 쓴 비용이 붙습니다.** `Subagents this session 2 (haiku 2) spent $0.02` 처럼 이번 세션이 실행한 서브에이전트의 비용을 실행마다 그 모델의 단가로 계산해 보여 줍니다. 세션 비용과 같은 경로로 계산하므로 게이트웨이 세션에서는 게이트웨이 단가표를 씁니다. 단가를 모르는 실행은 `+N unpriced` 로 개수를 붙이고, 하나도 계산하지 못하면 `n/a` 로 표시합니다.
