- **The Claude desktop app now shows sprag's statusline.** The desktop app's Code tab runs claude in stream-json mode and never runs settings.json's `statusLine.command`, so desktop sessions had no statusline, and none of the rate-limit and context-window snapshots the delegation briefing reads. The new `sprag-statusline` mod runs the same `sprag statusline` command and draws its output in the band above the prompt. It runs on the desktop surface only, so the terminal keeps its own statusline. A run that takes longer than three seconds is cut off, and a failure keeps the last text.
- **Password-protected and DRM documents are refused with a notice that they cannot be read.** Until now such a document passed the Read through, with a note asking the user for an unlocked copy. Company encryption is policy, so the doc2md hooks and the CLI now say in one shared sentence that the contents cannot be read, and tell the model not to try unlocking or converting it another way. The `sprag-doc2md` mod carries the same notice on the path where Claude Code refuses pptx, xlsx and docx as binary files before any settings hook runs.
- **In the desktop app's third-party mode, delegation is no longer suggested to a tier with no registered model.** That mode maps only the models registered in the app's settings to tiers, and a delegation to an unregistered tier runs on the session model and saves nothing. The prompt hint now drops such tiers, and when none is left it tells the model to work directly and to mention, once, that registering a model in the app's settings makes delegation work.
- **Model profiles are learned from the model a subagent actually ran on.** In third-party mode a `model: "haiku"` delegation that fell back to the session model could stamp the session's Opus profile as haiku, so its cost would have been priced at Haiku rates once the gateway price table aged out. The model a run declares in its transcript now decides, and only transcripts without a declaration fall back to the requested model as before.

## 한국어

- **Claude 데스크톱 앱에도 sprag 상태 줄이 나옵니다.** 데스크톱 앱의 Code 탭은 claude 를 stream-json 모드로 실행하므로 settings.json 의 `statusLine.command` 를 한 번도 실행하지 않았고, 그래서 데스크톱 세션에는 상태 줄도, 위임 브리핑이 참고하는 사용량 한도와 컨텍스트 창 기록도 남지 않았습니다. 새 mod `sprag-statusline` 이 같은 `sprag statusline` 명령을 실행해 그 결과를 프롬프트 위 영역에 그립니다. 데스크톱에서만 동작하므로 터미널은 기존 상태 줄을 그대로 씁니다. 실행이 3초를 넘기면 끊고, 실패하면 직전 내용을 유지합니다.
- **암호가 걸린 문서와 DRM 문서는 읽지 않고, 읽을 수 없다고 알립니다.** 지금까지는 이런 문서도 Read 를 통과시키고 잠금을 푼 사본을 달라고 사용자에게 요청하게 했습니다. 회사 문서 암호화는 보안 정책이므로, 이제 문서 변환 훅과 CLI 가 같은 안내 문장으로 내용을 읽을 수 없다고 알리고 잠금 해제나 다른 변환 경로를 시도하지 말라고 지시합니다. Claude Code 가 설정 훅보다 먼저 pptx·xlsx·docx 를 이진 파일로 거부하는 경로에서도 `sprag-doc2md` mod 가 같은 안내를 전달합니다.
- **데스크톱 앱의 서드파티 모드에서 등록되지 않은 모델로 위임을 권하지 않습니다.** 이 모드에서는 앱 설정에 등록한 모델만 티어에 연결되고, 등록하지 않은 티어로 위임하면 세션 모델이 그대로 실행되어 절감이 없습니다. 이제 프롬프트 안내가 그런 티어를 후보에서 빼고, 남는 티어가 없으면 직접 처리하라고 지시하면서 앱 설정에 모델을 등록하면 위임이 동작한다는 사실을 한 번 알려 줍니다.
- **서브에이전트가 실제로 실행된 모델을 기준으로 모델 프로필을 학습합니다.** 서드파티 모드에서 `model: "haiku"` 로 요청한 위임이 세션 모델로 대신 실행되면, 그 요청 하나 때문에 세션의 Opus 프로필이 haiku 로 기록되어 게이트웨이 단가표가 만료된 뒤 세션 비용이 Haiku 단가로 계산될 수 있었습니다. 이제 서브에이전트 기록에 남은 실행 모델 선언을 우선해서 판정하고, 선언이 없는 기록만 예전처럼 요청한 모델로 판정합니다.
