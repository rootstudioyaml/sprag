- **sprag installs tool-restricted delegation agents, so delegations stay light behind a gateway.** Behind a gateway (a non-first-party `ANTHROPIC_BASE_URL`) Claude Code turns MCP tool search off, so every subagent request carries every MCP schema along with the full built-in tool set. A subagent whose definition lists its tools carries only those. sprag now installs haiku-explore, haiku-runner, haiku-translate and sonnet-worker in `~/.claude/agents` at install and session start, none with MCP tools. Measured through a LiteLLM proxy, the first request dropped from 46,618 tokens for general-purpose to about 20,000. The rules add a fallback to general-purpose on the same model for tasks that need MCP. A user's own agent of the same name is never overwritten, and `sprag delegate agents on|off` toggles them.
- **The ratchet rules now reach the Claude app's Cowork tab.** The Cowork tab reads neither `~/.claude/settings.json` nor the `@` imports in `~/.claude/CLAUDE.md`, so no rule reached it and no delegation happened there. It does read `.claude/rules/*.md` in the folders the user connects, so sprag finds those folders from the app's session metadata and copies the three global ratchet files to `.claude/rules/sprag-cowork-ratchet.md`. The home directory, `~/.claude` and `~/Library` are skipped, git folders get a `.git/info/exclude` line instead of a `.gitignore` change, and settings.json gets a `claudeMdExcludes` entry so Claude Code does not load the copy twice. `sprag cowork` shows status and offers sync, on/off and per-folder exclusion.
- **The design/implementation split ships as a bundled preset.** The rule lived only in the header of ratchet-model.md, which route-scan writes after gathering enough history, so a fresh install did not have it. As preset fix-777a15 it is offered from the first session: the main model settles the design and spec, code writing goes to a sonnet subagent, and short edits stay on the main model. It names Claude tiers, so it is not offered to Codex sessions.
