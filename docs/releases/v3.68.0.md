- **The statusline's second row is shorter, and figures that are read as a pair share one precision.** The row ran to 229 columns, and what got clipped in an ordinary terminal was the part that never changed: `🅷 5/5` and `✍️ Korean style`. The 🅷 chip now appears only when the score is short or a warning is due, and the Korean style chip only when `--segments korean` asks for it. `Routing saved $14.4 · spent $4.57` becomes `$14.4 · spent $4.6`, a reset doc2md counter reads `$0` instead of `$0.00`, the registry check age reads `✓5m ago` rather than `✓5m`, which looked like a countdown, and a payload without a `display_name` shows `Fable 5.1` instead of `claude-fable-5-1`.
- **Unknown commands and options are refused instead of ignored.** `sprag install --dry-run` used to drop the option it did not know and run the real install, rewriting settings.json, and `sprag bogus` fell through to the 30-day report. Both now print `Unknown command` / `Unknown option` and exit with code 2 before anything is scanned or written. The statusline and `--hook-run` paths, which Claude Code calls with a fixed command line, only warn and carry on. A test compares the declared option list with every option the code actually reads.
- **Node.js 20 or newer is required.** Node 18 is past end of life and has left the CI matrix, which now runs Node 20, 22 and 24. The Windows jobs that had hung on every push since 2026-10-05 are green again: a test removed the sandbox it had made its working directory, and the detached update check kept a temp directory open; both are fixed.
- **The installer recognises a statusline wrapper script.** A `statusLine` command such as `bash ~/.claude/statusline-cts.sh` that calls sprag or claude-token-saver from inside a shell script was reported as a foreign command and skipped. It is now named as a wrapper, with a note when its `npx claude-token-saver@latest` fallback resolves to the old package that stopped at 3.55.0; `sprag install --force` replaces it.
- **Documentation and the site are tidied.** `docs/DOC2MD.md` and `docs/ROUTE_SCAN.md` mixed both languages in one file, so the English page showed Korean and there was no Korean page; each is now an English and a Korean file, and three statements that contradicted the code (`.fig` handling, binary refusal, the converter's automatic install) are corrected. The README's release notes had stopped at v3.54.0, the screenshot moved next to the install section, and sprag.io's first screen says what the tool does and shows the install command. Benchmark figures carry an "offline replay" qualifier and a source link, and every release body now ends with the upgrade command and a compare link.
- **The old name `claude-token-saver` stopped receiving updates at 3.55.0.** Its npm deprecation notice said "same releases"; it now says what is true. Move with `npm uninstall -g claude-token-saver && npm i -g sprag-cli`.

## 한국어

- **statusline 둘째 줄이 짧아지고, 짝으로 읽는 숫자가 같은 자릿수로 나옵니다.** 둘째 줄이 229칸까지 길어져서 보통 터미널에서는 꼬리가 잘렸는데, 잘리는 쪽은 늘 같은 말만 하던 `🅷 5/5` 와 `✍️ Korean style` 이었습니다. 이제 🅷 칩은 점수가 깎였거나 경고가 있을 때만 나오고, Korean style 칩은 `--segments korean` 으로 요청할 때만 나옵니다. `Routing saved $14.4 · spent $4.57` 처럼 한 쌍인 금액은 같은 자릿수(`$14.4 · spent $4.6`)로 맞추고, 리셋한 doc2md 카운터는 `$0.00` 대신 `$0` 으로, 등록소 확인 시각은 남은 시간처럼 읽히던 `✓5m` 대신 `✓5m ago` 로 표시합니다. `display_name` 이 없는 payload 에서도 `claude-fable-5-1` 전체 ID 대신 `Fable 5.1` 로 보입니다.
- **모르는 명령과 옵션은 조용히 넘어가지 않고 거부합니다.** `sprag install --dry-run` 처럼 없는 옵션을 붙이면 지금까지는 옵션만 버리고 실제 설치가 실행되어 settings.json 이 바뀌었고, `sprag bogus` 는 30일 전체 스캔 보고서로 떨어졌습니다. 이제 둘 다 무엇을 하기 전에 `Unknown command` / `Unknown option` 을 알리고 종료 코드 2로 끝납니다. statusline 과 `--hook-run` 은 settings.json 의 고정 명령으로 불리므로 경고만 남기고 평소대로 동작합니다. 선언한 옵션 목록과 실제 읽는 옵션이 어긋나면 테스트가 잡습니다.
- **Node.js 20 이상이 필요합니다.** Node 18 은 지원이 끝났고 CI 에서도 빠졌습니다. 테스트 매트릭스는 Node 20·22·24 로 바뀌었고, 2026-10-05 부터 Windows 에서 멈추던 CI 는 원인 두 가지(샌드박스 안에 작업 디렉터리를 둔 채 삭제, update-check 분리 자식이 임시 디렉터리를 점유)를 고쳐 다시 녹색이 됩니다.
- **설치기가 사용자의 statusline 래퍼 스크립트를 알아봅니다.** `bash ~/.claude/statusline-cts.sh` 처럼 셸 스크립트 안에서 sprag 나 claude-token-saver 를 부르는 설정은 "다른 명령"으로만 보고 건너뛰었습니다. 이제 래퍼라고 알리고, 그 안의 `npx claude-token-saver@latest` 폴백이 3.55.0 에서 멈춘 옛 패키지를 가리킨다는 점도 함께 적습니다. 바꾸려면 `sprag install --force` 입니다.
- **문서와 사이트를 정리했습니다.** `docs/DOC2MD.md` 와 `docs/ROUTE_SCAN.md` 는 한 파일에 두 언어가 섞여 있어 영문 페이지에 한국어가 나오고 한국어 페이지는 없었는데, 다른 문서처럼 영문·한국어 파일로 나누고 코드와 어긋난 설명 세 곳(`.fig` 처리, 이진 파일 거부, 변환기 자동 설치)을 바로잡았습니다. README 는 릴리스 노트가 v3.54.0 에 멈춰 있던 것을 고치고 스크린샷을 설치 절 옆으로 옮겼으며, sprag.io 첫 화면에는 무엇을 하는 도구인지와 설치 명령이 바로 보입니다. 벤치마크 수치에는 오프라인 재현이라는 단서와 출처 링크를 붙였습니다. 릴리스 본문 끝에는 업그레이드 명령과 compare 링크가 붙습니다.
