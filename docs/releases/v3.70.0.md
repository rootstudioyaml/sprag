- **An opt-in team layer: only machines that join send anything, and what they send is one aggregate row per day.** Join with `sprag team join <token>`, or set `SPRAG_TEAM_TOKEN` in the environment to enroll an organization at the next session start. From then on a detached child of the SessionStart hook uploads, at most every 6 hours, one row per local calendar day (spend, savings, delegated-run count and model-family share) to Supabase in ap-northeast-2, and pulls the rules the team approved. Prompts, transcripts, file paths and project names are never sent, and rule text goes up only through `sprag team propose`. `sprag team status --show-payload` prints the exact rows, `sprag team leave` removes the key, the cache and the import and wins over the environment, and `CTS_NO_TEAM_SYNC=1` stops all team traffic. An install that never joins sends nothing, exactly as before.
- **Team-approved rules arrive in `~/.claude/ratchet-team.md`.** The file is re-rendered from the cache at session start and imported from the global harness block only while it exists. Codex gets `<CODEX_HOME>/ratchet-team.md` through its SessionStart hook, and the Cowork copy includes it. A machine enrolled through the environment prints a one-line notice in its first session naming the team and the two commands that show and stop the upload.
- **sprag.io/team and sprag.io/pricing are live.** The owner signs in with an email code, creates a team and gets the invite token with three enrollment snippets: one command, a shell profile line, and Claude Code managed settings. The dashboard lists per-member spend, savings and delegated runs for 30 days, draws the daily chart, approves or removes rules, and removes members. Plans are Free, Team at $5 per seat per month and Team Plus at $10 with the prompt-capture policy; this CLI does not upload prompts yet and only shows the policy flag in `sprag team status`.
- **The network table lists the team layer.** docs/INSTALL.md gains a row for the Supabase RPC endpoint with its off switch, the sentence that no usage data leaves the machine now carries the team exception, and the new docs/TEAM.md covers what is sent and what is not, individual joins, organization enrollment, rules, files and environment variables.

## 한국어

- **팀 레이어가 생겼습니다. 옵트인이며, 참여한 PC 만 하루 단위 집계를 보냅니다.** `sprag team join <토큰>` 으로 참여하거나, 조직 배포용 `SPRAG_TEAM_TOKEN` 환경변수가 있으면 다음 세션 시작 때 참여합니다. 그 뒤 SessionStart 훅이 띄운 분리 자식이 6시간에 한 번, 로컬 날짜별로 지출·절감·위임 실행 횟수·모델 계열 비중 한 줄씩을 Supabase(ap-northeast-2)에 올리고 팀이 승인한 룰을 받아 옵니다. 프롬프트·트랜스크립트·파일 경로·프로젝트 이름은 보내지 않고, 룰 본문은 `sprag team propose` 로 직접 올릴 때만 갑니다. `sprag team status --show-payload` 가 올라갈 행을 그대로 보여 주고, `sprag team leave` 는 키와 캐시와 import 를 지우며 환경변수보다 우선합니다. `CTS_NO_TEAM_SYNC=1` 은 참여 여부와 무관하게 전송을 막습니다. 참여하지 않은 설치는 이전과 똑같이 아무것도 보내지 않습니다.
- **팀이 승인한 룰이 `~/.claude/ratchet-team.md` 로 들어옵니다.** 세션 시작 때 캐시에서 다시 그리고, 파일이 있는 동안만 전역 CLAUDE.md 의 하네스 블록에 import 줄을 넣습니다. Codex 는 `<CODEX_HOME>/ratchet-team.md` 를 SessionStart 훅이 주입하고, Cowork 사본에도 함께 들어갑니다. 조직 배포로 자동 참여된 PC 는 첫 세션에 팀 이름과 확인·해제 명령을 한 줄로 안내합니다.
- **sprag.io/team 대시보드와 sprag.io/pricing 요금 페이지가 열립니다.** 오너는 이메일 코드로 로그인해 팀을 만들고, 초대 토큰과 등록 스니펫 세 가지(개인 명령, 셸 프로필, Claude Code managed settings)를 받습니다. 멤버별 30일 지출·절감·위임 횟수, 하루 단위 차트, 룰 승인·제거, 멤버 제거가 있습니다. 요금은 Free, Team 좌석당 월 $5, Team Plus 좌석당 월 $10(프롬프트 수집 정책)이며, 프롬프트 업로드는 이번 CLI 에 없고 정책 플래그만 `sprag team status` 에 보입니다.
