- **Delegated runners execute heavy commands under a process cap.** The haiku-runner, sonnet-worker and opus-worker bodies now say to wrap a command that starts many processes (a full test suite, a build, a render) as `(ulimit -u <current user processes + 150>; command)` on macOS and Linux. At the cap the kernel refuses with `spawn ... EAGAIN`, so the culprit's command line survives instead of the machine stalling, and the runner reports that line as a runaway rather than a test failure. The self-relaunch runaway fixed in 3.71.0 happened while haiku-runner ran the full suite with no cap. `sprag install` rewrites the agent files.
- **A preset rule, `fix-bec8e9`, applies the same cap to the main model.** `sprag seed` and `sprag harness pull` offer it: run, or hand a subagent, a heavy command only under the cap; never rerun on `EAGAIN`, take a `ps` snapshot and find the command that multiplied; and code that starts a background child uses an entry path resolved from the module's location plus a re-entry marker, never `process.argv[1]`.

## 한국어

- **위임 러너가 무거운 명령을 프로세스 상한 안에서 돌립니다.** haiku-runner, sonnet-worker, opus-worker 본문에 전체 테스트·빌드·렌더처럼 프로세스를 여럿 띄우는 명령은 `(ulimit -u <현재 사용자 프로세스 수+150>; 명령)` 으로 감싸라는 지침이 들어갔습니다(macOS·Linux). 상한에 걸리면 커널이 `spawn ... EAGAIN` 으로 거절해 머신이 멈추는 대신 범인 명령줄이 남고, 러너는 그 줄을 폭주 신호로 보고합니다. 3.71.0 에서 고친 자기 복제 폭주는 haiku-runner 가 전체 테스트를 상한 없이 돌리다 일어났습니다. `sprag install` 이 에이전트 파일을 다시 씁니다.
- **같은 상한을 메인 모델에도 거는 프리셋 룰 `fix-bec8e9` 가 추가됐습니다.** `sprag seed` 와 `sprag harness pull` 이 제안하며, 무거운 명령을 직접 돌리거나 서브에이전트에 맡길 때 상한을 걸고, `EAGAIN` 을 재실행하지 말고 `ps` 스냅샷으로 폭주 명령을 찾으라고 적혀 있습니다. 백그라운드 자식을 띄우는 코드는 `process.argv[1]` 대신 모듈 위치에서 구한 진입점과 재진입 마커를 쓰라는 조항도 같이 담았습니다.
