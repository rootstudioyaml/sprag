- **The preset signing key ships with the CLI.** `PRESET_SIGNING_KEYS` now holds the public half of the key created on 2026-10-20 (fingerprint `8bc624f874f5620a`), so from this version a preset bundle signed with it on sprag.io/ops is fetched and applied. An unsigned bundle, or one signed with another key, is ignored as before and the bundled presets stay in use. `sprag presets status` shows the listed fingerprint.
- **A model-routing rule now names only its tier; the agents preset says which agent serves it.** Presets and the rules route-scan writes drop the `agent` field and keep the category and tier (T2, T1, T1H). Each delegation agent carries the `tier` it serves and its `categories` (`*` for all), so Claude delegates to the first agent that matches and Codex uses the model mapped to the same tier. With the bundled presets the rule text is unchanged (haiku-runner for running commands, haiku-explore for lookup, reading, checks and pasted logs, sonnet-worker for T1, opus-worker for T1H). A rule that still carries `agent`, from an older registry or the published v1 bundle, keeps that name. The /ops console's model table shows a Claude agent column next to a Codex column, and the agent form picks a tier and categories.
- **The two bundled ratchet presets that were scoped to one tool are offered to every tool.** `fix-f558f9` (delegate simple requests) and `fix-777a15` (design and implementation split) were Claude-only, so Codex sessions never saw them. Both now say to delegate to a tier, with one clause on how each tool turns that tier into a model. The ids are unchanged, so machines that accepted them get the new wording.
