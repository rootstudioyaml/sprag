- **Codex delegates under the same role as Claude.** When Codex is pointed at a shared delegation rule, each tier's model now carries the role name and the first sentence of that role's body (e.g. `T2: model <mapped model>. Role t2-runner: …`). The implementation-split hint names the t1-worker role, and the model-routing offers in `sprag seed --agent codex` say `tasks use T2 as role t2-runner`. The role is resolved by the same rule as the agent Claude delegates to, so the /ops console's model-routing table shows one value for both tools, such as `T2 → t2-runner`, in a single column instead of two. Claude runs the role as an agent file; Codex runs the same role body on the model mapped to that tier.
- **The five delegation agents are named by tier, not by model.** `haiku-explore`, `haiku-runner`, `haiku-translate`, `sonnet-worker` and `opus-worker` are now `t2-explore`, `t2-runner`, `t2-translate`, `t1-worker` and `t1h-worker`, so a name no longer goes stale when the model behind a tier changes. The old names keep resolving: a rule or registry that still carries one maps to the new name, and when only the old file is installed the rule points at that file. `sprag install` removes its own old files and leaves any file you edited. The two bundled ratchet rules `fix-f558f9` and `fix-777a15` no longer branch per tool and name only the T2 and T1 agents.

- **Codex 도 Claude 와 같은 위임 역할로 일을 맡깁니다.** 공유 위임 룰을 Codex 에 안내할 때 티어별 모델 뒤에 역할 이름과 그 역할 본문의 첫 문장을 붙입니다(예: `T2: model <매핑된 모델>.
