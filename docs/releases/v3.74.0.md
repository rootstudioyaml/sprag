- **Codex delegates under the same role as Claude.** When Codex is pointed at a shared delegation rule, each tier's model now carries the role name and the first sentence of that role's body (e.g. `T2: model <mapped model>. Role haiku-runner: …`). The implementation-split hint names the sonnet-worker role, and the model-routing offers in `sprag seed --agent codex` say `tasks use T2 as role haiku-runner`. The role is resolved by the same rule as the agent Claude delegates to, so the /ops console's model-routing table shows one value for both tools, such as `T2 → haiku-runner`, in a single column instead of two. Claude runs the role as an agent file; Codex runs the same role body on the model mapped to that tier.

## 한국어

- **Codex 도 Claude 와 같은 위임 역할로 일을 맡깁니다.** 공유 위임 룰을 Codex 에 안내할 때 티어별 모델 뒤에 역할 이름과 그 역할 본문의 첫 문장을 붙입니다(예: `T2: model <매핑된 모델>. Role haiku-runner: …`). 구현 분업 안내는 sonnet-worker 역할을, `sprag seed --agent codex` 의 모델 라우팅 제안은 `역할은 haiku-runner이고 실행 모델은 Codex가 티어 매핑으로 정합니다` 처럼 역할을 적습니다. 역할은 Claude 가 위임하는 에이전트와 같은 규칙으로 정해지므로, /ops 콘솔의 모델 라우팅 표는 두 열 대신 `T2 → haiku-runner` 처럼 두 도구에 공통인 값을 한 열에 보여 줍니다. Claude 는 이 역할을 에이전트 파일로 실행하고, Codex 는 같은 역할 본문을 그 티어에 매핑된 모델로 실행합니다.
