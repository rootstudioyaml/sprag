- **Delegation hints now show the model and effort an agent really runs on.** A rule names only the tier agent (`t1-worker`), and Claude Code draws the call row as `t1-worker(…)`, so neither said which model ran or at what effort. The rule text now reads `model:` and `effort:` from the installed agent file and adds them, as in `t1-worker(Sonnet 5.5 · effort medium. …)`. A project copy wins over the one in your user directory. A full model id is shortened to `Sonnet 5.5`; an alias such as `sonnet` stays as written, because it can resolve to an older model.
- **The 🔀 delegation line and the Agent call row carry the same values.** The line now reads `🔀 [sprag] model fitting: "<category>" → delegated to <agent> (<model> · effort <effort>)`, and ratchet-model.md and the per-request hint ask the session to start the Agent tool's description with `[<model> · <effort>]`, so the call row reads like `t1-worker([Sonnet 5.5 · medium] …)`.
