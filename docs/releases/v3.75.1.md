- **The LiteLLM budget refresh no longer piles up login windows while you are away.** The background process that refreshes the budget gauge runs `apiKeyHelper` every five minutes whether or not anyone is at the keyboard, so once the cached token expired, a browser-based helper such as Okta opened a new login window on every refresh. The helper now runs with `APIKEY_HELPER_NONINTERACTIVE=1`, so a helper that checks the variable fails fast instead of opening a window when it has no cached token. Helpers that ignore the variable behave as before.

## 한국어

- **LiteLLM 예산 갱신이 자리를 비운 동안 로그인 창을 쌓지 않습니다.** 예산 게이지를 갱신하는 백그라운드 프로세스는 사용자 입력과 무관하게 5분마다 `apiKeyHelper` 를 실행합니다. 그래서 캐시된 토큰이 만료되면 Okta 같은 브라우저 인증 헬퍼가 갱신 때마다 로그인 창을 새로 띄웠습니다. 이제 헬퍼에 `APIKEY_HELPER_NONINTERACTIVE=1` 을 넘기므로, 이 변수를 확인하는 헬퍼는 캐시된 토큰이 없을 때 창을 띄우지 않고 바로 실패합니다. 이 변수를 모르는 헬퍼는 전처럼 동작합니다.
