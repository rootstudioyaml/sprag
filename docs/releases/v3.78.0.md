Approved rules ride on this sync, so they reach new sessions sooner.
- **Prompt capture sends only prompts a person typed.** Background-task notifications, messages from other agents and `!` shell commands with their output were going up as if typed; they no longer do. - **Operators open organizations, and owners and admins sign in by email invitation.** The self sign-up route on /team is gone. The License page separates the free Apache-2.0 CLI from the paid team features, which are offered on request, and lays out the four steps (get in touch, order and pay, organization opened, invite the team) and what Sprag works with: Anthropic Claude Code and OpenAI Codex, personal subscriptions and API keys, and AWS Bedrock.
