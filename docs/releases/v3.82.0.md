- **You can now change your display name after joining a team with `sprag team name "<name>"`.** The dashboard shows the new name at once, and the days already uploaded stay with the same member. A machine that auto-joined through `SPRAG_TEAM_TOKEN` and shows as `member-xxxxxxxx` is renamed the same way, and while the name is still the member ID, `sprag team status` and `sprag team join` point at the command. Joining again without `--name` keeps the name this machine last used.
- **In IntelliJ's terminal the statusline team chip shows the animal's name and rank without the emoji.** The IDE font has no animal emoji, so the chip used to garble; it now reads like `member-1e500474 Fox #3 of 12`. Narrow and text mode follow the same rule, and `sprag mode icon-force` brings the emoji back.

## 한국어

- **팀에 참여한 뒤에도 `sprag team name "<이름>"` 으로 표시 이름을 바꿀 수 있습니다.** 대시보드에 새 이름이 바로 나오고, 이미 올라간 날짜별 집계는 같은 구성원에 그대로 남습니다. `SPRAG_TEAM_TOKEN` 으로 자동 참여해 `member-xxxxxxxx` 로 표시되던 컴퓨터도 같은 방법으로 바꾸며, 이름이 아직 구성원 ID이면 `sprag team status` 와 `sprag team join` 이 이 명령을 안내합니다. `--name` 없이 다시 참여하면 이 컴퓨터가 마지막으로 쓴 이름을 그대로 씁니다.
- **IntelliJ 터미널에서는 statusline 팀 칩이 동물 이모지 없이 이름과 순위만 보여 줍니다.** IDE 글꼴에 동물 이모지가 없어 칩이 깨졌으므로, 이제 `member-1e500474 여우 12명 중 3위` 처럼 표시합니다. narrow 모드와 text 모드도 같은 규칙을 따르며, `sprag mode icon-force` 를 켜면 이모지가 다시 나옵니다.
