- **A machine running a version below its organization's minimum now upgrades itself without asking.** When the Sprag operator sets a minimum version for an organization in the ops console, machines receive it with the team rules and, at the next session start, run `sprag upgrade --org-policy` as a detached background process; install output goes to `org-upgrade.log` in the user data directory, the result is reported at the following session, and `sprag team status` shows the minimum and the last outcome. Every other upgrade still waits for consent, and a copy run from a git checkout never upgrades itself.
- **Daily usage now includes Claude desktop Cowork sessions and compressed Codex rollouts.** Cowork runs Claude Code with its own config directory, so it was never counted; it is now added to `spent_usd` and `claude_spent_usd`, and Codex rollouts compressed to `.jsonl.zst` no longer drop out of the totals. Cowork transcripts are read locally only, and only daily totals leave the machine, as before.
- **Usage is now priced with the LiteLLM gateway's long-context tier rates.** The gateway bills a request whose prompt exceeds a tier threshold (272K for the GPT models, 100K for Haiku 5.5) at the tier rates, so Codex usage is priced request by request using each request's own prompt length, and an older price snapshot is refreshed once.
- **A team sync started from a Codex hook now uses the gateway address from Claude settings.** A Codex process lacks the gateway address Claude Code sets, so it priced Claude usage at list rates and sent no gateway figure, making the same daily row change with whichever agent synced last; the address is now filled from `~/.claude/settings.json` when the environment has none, and an address already set is left alone.

## 한국어

- **조직 운영자가 정한 최소 버전보다 낮은 컴퓨터는 묻지 않고 스스로 업그레이드합니다.** Sprag 운영자가 ops 콘솔에서 조직마다 최소 버전을 정하면, 컴퓨터가 팀 룰과 함께 그 값을 받아 다음 세션을 시작할 때 분리된 백그라운드 프로세스로 `sprag upgrade --org-policy` 를 실행합니다. 설치 출력은 사용자 데이터 디렉터리의 `org-upgrade.log` 에 쌓이고 결과는 다음 세션에서 알려 주며, `sprag team status` 에서 최소 버전과 마지막 결과를 볼 수 있습니다. 그 밖의 업그레이드는 지금처럼 동의를 기다리고, git 체크아웃에서 실행한 사본은 스스로 업그레이드하지 않습니다. 자세한 내용은 [팀 문서](./docs/TEAM.ko.md)의 "조직 최소 버전" 절에 있습니다.
- **하루 사용량에 Claude 데스크톱 앱의 Cowork 세션과 압축된 Codex 롤아웃이 포함됩니다.** Cowork 는 별도 설정 디렉터리에서 Claude Code 를 실행하므로 지금까지 세지 못했고, 이제 `spent_usd` 와 `claude_spent_usd` 에 더합니다. Codex 가 오래된 롤아웃을 `.jsonl.zst` 로 압축하면 그 금액이 빠지던 문제도 고쳤습니다. Cowork 기록은 로컬에서만 읽고, 밖으로 나가는 것은 지금처럼 하루 합계뿐입니다.
- **사용량 금액에 LiteLLM 게이트웨이의 장문맥 구간 가격을 반영합니다.** 프롬프트가 구간 기준(GPT 모델 272K, Haiku 5.5 100K)을 넘는 요청은 게이트웨이가 구간 단가로 청구하므로, Codex 사용량을 요청마다 그 요청의 프롬프트 길이로 구간을 골라 계산합니다. 가격 스냅샷은 한 번 새로 받아 옵니다.
- **Codex 훅이 시작한 팀 동기화도 Claude 설정의 게이트웨이 주소를 씁니다.** Codex 프로세스에는 Claude Code 가 설정한 게이트웨이 주소가 없어서 Claude 사용량을 정가로 계산하고 게이트웨이 금액을 보내지 않았습니다. 그래서 같은 날의 행이 마지막으로 동기화한 에이전트에 따라 바뀌었습니다. 이제 환경에 주소가 없으면 `~/.claude/settings.json` 에서 채우고, 이미 주소가 있으면 건드리지 않습니다.
