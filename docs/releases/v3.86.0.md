- **Session start now says when a delegation agent file you edited yourself differs from the preset.** sync treats a `~/.claude/agents/<name>.md` without the sprag marker as yours and never overwrites it, but it did so silently, so when the preset raised t1-worker to effort high a hand-edited file stayed at medium; a differing effort or model family is now announced once per preset version, and `sprag delegate agents` shows the file value beside the preset value on every status line. To let sprag manage the file again, delete it and run `sprag delegate agents on`.
- **Codex's automatic tier models now carry the preset agents' effort.** A tier you did not map resolves to a cheaper model Codex has already run, but no `reasoning_effort` went with it, so the child ran at the model's default and preset effort changes never reached Codex; each automatic tier now sends the effort its agents share (T2 low, T1 and T1H high), `delegate shared status` shows it, and a tier mapped with `delegate shared map` keeps the value you set.
- **The heavy implementation worker (t1h-worker) uses the `opus` alias instead of a full model id.** Like the other delegation agents, a gateway can now remap it through `ANTHROPIC_DEFAULT_OPUS_MODEL`; current Claude Code resolves `opus` to `claude-opus-5-5` on the Anthropic API, so machines that connect directly behave the same.

## 한국어

- **직접 고친 위임 에이전트 파일이 프리셋과 다르면 세션 시작 때 알려 줍니다.** sync 는 sprag 표지가 없는 `~/.claude/agents/<이름>.md` 를 사용자 파일로 보고 덮어쓰지 않는데, 지금까지는 이 동작이 조용히 일어나서 프리셋이 t1-worker 의 effort 를 high 로 올려도 직접 고친 파일은 medium 에 머물렀습니다. 이제 effort 가 다르거나 모델 계열이 다르면 프리셋 버전마다 한 번 알리고, `sprag delegate agents` 상태 줄에도 파일 값과 프리셋 값을 함께 보여 줍니다. sprag 가 관리하게 하려면 파일을 지운 뒤 `sprag delegate agents on` 을 실행합니다.
- **Codex 의 자동 티어 모델에 프리셋 에이전트의 effort 를 함께 보냅니다.** 직접 매핑하지 않은 티어는 Codex 가 이미 실행한 더 싼 모델로 정해지는데, 그동안 `reasoning_effort` 를 보내지 않아 모델 기본값으로 실행됐고 프리셋의 effort 변경도 Codex 에는 닿지 않았습니다. 이제 T2 는 low, T1 과 T1H 는 high 처럼 그 티어 에이전트들이 공유하는 값을 보내고, `delegate shared status` 에도 표시합니다. `delegate shared map` 으로 직접 매핑한 티어는 지정한 값을 그대로 씁니다.
- **고난도 구현 워커(t1h-worker)가 전체 모델 ID 대신 `opus` 별칭을 씁니다.** 다른 위임 에이전트처럼 게이트웨이가 `ANTHROPIC_DEFAULT_OPUS_MODEL` 로 모델을 바꿔 연결할 수 있게 하려는 변경이며, 현재 Claude Code 는 Anthropic API 에서 `opus` 를 `claude-opus-5-5` 로 연결하므로 직접 접속하는 컴퓨터의 동작은 같습니다.
