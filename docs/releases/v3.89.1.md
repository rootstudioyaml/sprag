- **On Windows, a merged base statusline no longer flashes a console window on every refresh.** The path that runs your previous statusline command (`statuslineBase`) ahead of sprag's started it through a shell without hiding the window. It now runs hidden. macOS and Linux are unchanged.

## 한국어

- **Windows에서 기존 상태줄을 합쳐 쓰면 상태줄이 갱신될 때마다 콘솔 창이 깜빡이던 문제를 고쳤습니다.** sprag 상태줄 앞에 원래 쓰던 상태줄 명령(`statuslineBase`)을 이어 붙이는 경로가 그 명령을 셸로 실행하면서 창을 숨기지 않았습니다. 이제 그 명령은 창을 띄우지 않고 실행됩니다. macOS와 Linux 동작은 바뀌지 않습니다.
