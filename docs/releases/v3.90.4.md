- **When the ledger changes the savings of a past day, the team sync uploads again from that day.** The sync used to send only the days from the one before its last upload, so a rescan that repriced last week's delegations on the new basis, or found a delegation late, left the town and the team dashboard on the old figures. The ledger now remembers the earliest day whose figures changed, and the next sync re-sends from that day through today (at most 30 days) before clearing the mark; if the ledger changes again during the upload, the mark stays for the next sync. The first sync after upgrading re-sends the whole 30-day window once so the figures repriced in v3.90.0 reach the team, and since each day's row is overwritten, nothing is counted twice.
- **The Claude Code statusline capture on sprag.io and in the README now shows the share of spend by model.** The old capture dated from v3.58.0 and had no "Model used" share on the routing line, and the capture script leaves out the team chip, which prints this machine's member id.
- **The savings card's footnotes no longer squeeze into the right-hand column.** They now run under both columns.
