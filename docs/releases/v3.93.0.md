- **Enterprise users signed in with claude.ai get a budget gauge in the statusline.** Claude Code sends these users no `rate_limits`, so there was nothing to draw. Sprag now reads the usage-credit limit and spend from `/api/oauth/usage` in the background every five minutes and draws `💳 budget ▰▱ 54% $271/$500`. It is on by default; turn it off with `sprag mode no-oauth-budget` or `SPRAG_OAUTH_BUDGET=0`. Gateway, API key, Bedrock and Vertex users are skipped, and Pro and Max logins send no request. The OAuth token stays in memory and never reaches a file or log. Check the state with `sprag oauth-budget`.
- **A Claude apps gateway spend limit shows with its amounts.** `rate_limits.spend_limit` in the statusline input used to render as a bare `⏱ SL 63%`. It now draws like the LiteLLM budget, `💳 budget ▰▱ 63% $314/$500`, and the month estimate chip steps aside next to it. Claude Code 2.1.284 or later sends the amounts.
- **The rules tab on sprag.io/team shows the published Sprag preset rules, read only.** Organization owners and admins can see the preset bundle now being served next to their organization and team rules. Editing and publishing stay with the superuser on the ops console.
