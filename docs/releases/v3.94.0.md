- **The monthly offer to reset the savings counters now comes back at every new session until it is answered.** It used to record the month as asked the moment it printed, so a session nobody read used up the month's only ask. Now it stops only when the user says yes, which runs `sprag saved reset all`, or no, which runs the new `sprag saved keep`. A no keeps it quiet until the 1st of next month. A record left by v3.91.0 to v3.93.0 does not count as an answer, so users who missed this month's offer get it again.
- **`claude -p` and Agent SDK sessions no longer get the reset offer.** These sessions are mostly batch jobs nobody watches. On 2026-11-01 an unattended localization job took November's offer, and the interactive sessions after it showed nothing. Interactive terminal and VS Code sessions are asked as before.

## 한국어

- **매달 절감 집계 초기화 안내가 답을 받을 때까지 새 세션마다 나옵니다.** 지금까지는 안내를 출력하는 순간 그달에 물은 것으로 기록해서 아무도 읽지 않은 세션이 그달의 한 번을 써 버렸습니다. 이제 승낙해 `sprag saved reset all`을 실행하거나 거절해 새 명령 `sprag saved keep`을 실행해야 안내가 멈춥니다. 거절하면 다음 달 1일까지 묻지 않습니다. v3.91.0부터 v3.93.0이 남긴 기록은 답으로 치지 않으므로 이번 달 안내를 못 본 사용자도 다시 안내를 받습니다.
- **`claude -p`와 Agent SDK 세션에는 초기화 안내를 넣지 않습니다.** 이런 세션은 대부분 사람이 보지 않는 배치 작업입니다. 실제로 2026-11-01에 무인 현지화 작업이 11월 안내를 받아 갔고 그 뒤 대화형 세션에서는 안내가 나오지 않았습니다. 대화형 터미널과 VS Code 세션은 그대로 안내합니다.
