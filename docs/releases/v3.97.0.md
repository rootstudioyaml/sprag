- **Opening a recommended delegation rule now shows who saved how much.** Each member gets one line with the team, delegation count, failure rate, savings, start date and origin, sorted by savings, and machines that share a seat count once.
- **Rules that the Sprag preset bundle already ships are no longer recommended.** The preset reaches every machine on its own, so the list keeps only rules that members learned from their own route-scan, and a badge on each recommendation says how many members learned it.
- **The rule summary now carries its origin.** For each category and tier it says whether the rule came from the preset, from route-scan, or from both; rule text, examples and project paths still stay on the machine.

## 한국어

- **추천 위임 규칙을 펼치면 누가 얼마나 아꼈는지 보입니다.** 멤버마다 팀, 위임 횟수, 실패율, 절감액, 시작일, 출처가 한 줄씩 나오고 절감액이 큰 순서로 정렬됩니다. 같은 좌석을 쓰는 PC는 한 명으로 합칩니다.
- **Sprag 프리셋에 이미 들어 있는 규칙은 추천하지 않습니다.** 프리셋 규칙은 프리셋으로 모든 PC에 전달되므로 추천 목록에는 멤버가 자기 route-scan으로 학습한 규칙만 남습니다. 추천 머리의 배지가 자체 학습한 멤버 수를 알려 줍니다.
- **룰 요약에 출처가 함께 올라갑니다.** 각 카테고리와 티어의 룰이 프리셋에서 왔는지(preset), route-scan이 학습했는지(scan), 둘 다인지(both)를 담습니다. 룰 본문과 예시, 프로젝트 경로는 지금처럼 PC에 남습니다.
