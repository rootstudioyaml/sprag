- **`sprag routing off` turns model delegation off in one step.** It is for users who want the statusline, document conversion and the other features without delegation; from the next session `ratchet-model.md` carries only a note that delegation is off, and the two delegation presets and the model-fitting suggestions are left out. The per-prompt delegation hint, the candidate and rule-health notices, the `route?` and `rule-health` statusline chips and the Codex routing hint stop as well.
- **Turning it off keeps your registered rules and agent files.** `sprag routing on` brings the same rules back, and `sprag routing` shows the current state and how many rules are registered; a missing setting means on, so upgrading changes nothing. To remove the agent files as well, run `sprag delegate agents off` as before.
- **Every sprag.io header link is now reachable on phones, and the town detail shows a single usage total.** The rule that hid some header links on narrow screens is gone, and the town detail drops the local and unrecorded usage rows in favour of one total line.
