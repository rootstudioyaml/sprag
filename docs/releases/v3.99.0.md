- **The team dashboard creates several teams in one run.** Under "+ New team", open "Create several teams at once" and paste one team name per line to create up to 50 teams; names already in the organization, names listed twice and names over 80 characters are skipped and listed, and if one creation fails the run stops there and keeps the remaining names in the box.
- **Each team's join command can be exported as CSV.** "Export join commands", under the Teams list and on the Town tab, downloads one row per team with its invite token, `sprag team join` command, `SPRAG_TEAM_TOKEN` shell line and managed settings JSON, and after a bulk run a button exports only the teams it created.
- **The Invite & enroll tab and the empty-list hint build the join command with the same function as the export.** The command string is assembled in one place, so what the dashboard shows always matches the CSV; the member CLI is unchanged.

## 한국어

- **팀 대시보드에서 여러 팀을 한 번에 만듭니다.** "+ 새 팀"에서 "여러 팀 한 번에 만들기"를 펼쳐 한 줄에 팀 이름을 하나씩 붙여 넣으면 한 번에 50개까지 만들어집니다. 조직에 이미 있는 이름과 목록에 두 번 나온 이름, 80자를 넘는 이름은 건너뛰고 따로 알려 줍니다. 중간에 하나가 실패하면 그 이름에서 멈추고 남은 이름을 입력란에 남겨 둡니다.
- **팀별 가입 명령어를 CSV로 내보냅니다.** 팀 목록과 타운 탭의 "가입 명령어 내보내기"를 누르면 팀마다 초대 토큰, `sprag team join` 명령, `SPRAG_TEAM_TOKEN` 셸 줄, 관리형 설정 JSON이 한 줄씩 담긴 파일을 받습니다. 일괄 생성이 끝나면 방금 만든 팀만 내보내는 버튼도 나옵니다.
- **초대 탭과 빈 목록 안내의 가입 명령을 내보내기와 같은 함수로 만듭니다.** 명령 문자열을 한 곳에서만 조립하므로 화면에 보이는 명령과 CSV 내용이 어긋나지 않습니다. 멤버 쪽 CLI 동작은 바뀌지 않습니다.
