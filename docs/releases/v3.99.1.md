- **The compact-window audit reads the per-model window that `/autocompact` saves.** Since Claude Code 2.1.288, `/autocompact 500k` stores the value under `modelSettings.<model id>.autoCompactWindow` rather than the top-level `autoCompactWindow`, and sprag only read the top-level key, so it kept reporting the window as unset ([#11](https://github.com/rootstudioyaml/sprag/issues/11)). Each settings file is now checked for the model's own entry before its top-level key; `[1m]`, dated ids and Bedrock or Vertex spellings fold to the same entry the way Claude Code matches them, and a bare alias such as `opus` is never guessed to a version: the session's real model id from the statusline payload picks the entry, so a session switched with `/model` is judged against its own entry. A saved `auto` is a deliberate choice of the model default, so it is no longer warned about.
- **`sprag compact-window off` now silences the session briefing as well as the statusline chip.** The briefing used to fire once per session regardless of the switch.
- **`sprag compact-window set` now asks whether the value covers every model or one model.** `--all-models` writes the top-level `autoCompactWindow` and removes the per-model values in that file so every model really uses it, while `--model <model id>` writes only that model's `modelSettings` entry, the slot `/autocompact` uses; one of the two is required, and a bare alias such as `opus` is refused because its version is unknown. Per-model values are only read by Claude Code 2.1.288 or later, so wherever `--model` is offered or written sprag shows the installed Claude Code version and whether the value will apply.
- **The default compaction point in the text matches the docs.** A model with a native 1M window compacts at about 967K tokens by default, so the briefing, the command output and the HARNESS docs no longer say "near 800k"; the command table's default pin (500k) and the Korean HARNESS page's warning ceiling (700k) are corrected with it.

## 한국어

- **`/autocompact`가 모델별로 저장한 압축 창을 읽습니다.** Claude Code 2.1.288부터 `/autocompact 500k`는 값을 최상위 `autoCompactWindow`가 아니라 `modelSettings.<모델 id>.autoCompactWindow`에 저장하는데 sprag는 최상위 키만 읽어 "미설정"으로 경고했습니다([#11](https://github.com/rootstudioyaml/sprag/issues/11)). 이제 설정 파일마다 모델별 항목을 최상위 키보다 먼저 읽습니다. `[1m]`과 날짜, Bedrock, Vertex 표기는 Claude Code가 하듯 같은 항목으로 접습니다. `opus` 같은 별칭이 어느 버전인지는 추측하지 않고 상태줄이 보고한 세션의 실제 모델 id로 항목을 찾으므로 `/model`로 바꾼 세션도 그 모델의 항목으로 판정합니다. `/autocompact auto`가 저장한 `auto`는 사용자가 모델 기본값을 직접 고른 것이므로 경고하지 않습니다.
- **`sprag compact-window off`가 세션 브리핑도 끕니다.** 이전에는 상태줄 칩만 꺼지고 브리핑은 세션마다 한 번씩 계속 나왔습니다.
- **`sprag compact-window set`은 모든 모델에 같은 값을 쓸지 한 모델에만 쓸지 고르게 합니다.** `--all-models`는 최상위 `autoCompactWindow`에 쓰고 같은 파일의 모델별 값을 지워 모든 모델이 같은 값을 쓰게 합니다. `--model <모델 id>`는 `/autocompact`와 같은 자리인 그 모델의 `modelSettings` 항목에만 씁니다. 둘 중 하나를 꼭 지정해야 하며 `opus` 같은 별칭은 버전을 알 수 없어 받지 않습니다. 모델별 값은 Claude Code 2.1.288 이상에서만 쓰이므로 `--model`을 안내하거나 쓸 때 설치된 Claude Code 버전과 적용 여부를 함께 알려 줍니다.
- **기본 압축 시점 문구를 문서에 맞췄습니다.** 네이티브 1M 모델은 기본값으로 약 967K 토큰에서 압축하므로 브리핑, 명령 출력, HARNESS 문서의 "80만 토큰 근처"를 고쳤습니다. 함께 `compact-window` 명령 표의 기본 고정값(50만)과 HARNESS 한국어 문서의 경고 상한(70만)도 바로잡았습니다.
