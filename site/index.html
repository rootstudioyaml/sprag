claude-token-saver

Claude Code에서 비싼 모델이 반복하던 쉬운 작업을 더 싼 모델로 내려보내고, 아낀 금액을 statusline에 보여 주는 CLI입니다. 의존성은 없고 설치는 한 줄입니다.

실시간 라우터가 아닙니다

이 도구는 요청을 실시간으로 가로채지 않습니다. 세션이 끝난 뒤에 로컬 기록을 읽어서 비싼 모델이 반복해서 처리해 온 쉬운 유형을 찾아내고, 그 유형은 다음 세션부터 더 싼 모델이 맡도록 룰로 등록합니다. 추가로 LLM을 호출하지 않으므로 분석 자체에 드는 비용도 없습니다.

실시간 모델 라우팅이 오히려 비용을 키우는 이유

프롬프트 캐시는 모델별로 따로 유지됩니다. 그래서 세션 중간에 더 싼 모델로 전환하면 새 모델은 빈 캐시에서 시작하고, 그때까지 쌓인 대화 전체를 정가로 다시 읽어야 합니다. 캐시 히트는 원래 입력가의 10분의 1 수준이므로, 대화가 2만 토큰만 넘어가도 전환 한 번에 그날 아낀 금액이 통째로 사라집니다. 싼 모델로 옮겼는데 청구서는 더 커지는, 실시간 라우팅의 대표적인 역설입니다.

이 도구는 메인 세션의 모델을 건드리지 않습니다. 서브에이전트 위임만 사용하므로 메인 세션의 캐시는 그대로 유지되고, 위임된 작업만 별도 컨텍스트에서 싼 모델이 처리합니다.

절감액은 추정이 아니라 원장 기록입니다

위임된 실행 하나하나에 대해, 룰이 승격되기 전에 그 유형을 처리하던 기준 모델과 실제로 처리한 모델의 가격표를 같은 토큰량에 각각 적용하고, 그 차액을 기록합니다.

$ claude-token-saver route-scan savings

🔀 라우팅 절감 누적 $2.09  (최근 7일 $1.40 · 30일 $2.09)

모델 이동별:
  claude-fable-5 → claude-sonnet-5   —  1회, $0.72
  claude-opus-5 → claude-haiku-4-5   —  1회, $0.57

등록된 룰이 담당하지 않는 위임과, 가격표가 인식하지 못하는 모델명은 집계에서 제외합니다. 정직한 숫자가 큰 숫자보다 낫기 때문입니다.

statusline이 잡아 주는 것

  • 한도 초과 예방: 5시간과 7일 rate-limit 윈도가 90%에 닿으면 경고합니다.
  • 캐시 낭비 감지: 히트율과 TTL, 1M 컨텍스트를 감지해 토큰이 급증한 원인을 짚어 줍니다.
  • 한국어 문체 교정: 한국어 환경이면 자동으로 켜집니다.

English summary

claude-token-saver routes the easy work your expensive Claude model keeps repeating down to haiku or sonnet. It is a post-hoc session analyzer, not a realtime router, and it makes no extra LLM calls.

Because prompt caches are kept per model, switching models mid-session forces the new model to re-read the whole conversation at full price. This tool never changes the main session's model; it only delegates matched work to cheaper subagents, so the main cache stays warm. Savings are recorded in a ledger per delegated run, not estimated.

It also ships a statusline (rate-limit windows, cache hit rate, TTL countdown, context usage), a five-principle harness that blocks unverified "it's done" reports, an error ratchet, and doc2md, which converts pptx, xlsx, pdf, docx and fig files to Markdown before the model reads them. Zero dependencies, one-line install:

npm i -g claude-token-saver

Requires Node.js 18 or newer. MIT licensed. Full documentation is in the English README.
